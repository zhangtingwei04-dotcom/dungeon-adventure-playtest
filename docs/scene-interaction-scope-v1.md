# 燈火核心系統｜場景操作分層 V1.1

2026-11-26：依手機操作回饋，將事件類入口移至右下方。

## 操作規範

- 右下方：主要行動（探索、移動、休息）及事件入口（主線、特殊遭遇、委託等）。保留「調查／其他行動」作為上方細部互動入口。
- 右上方：情境互動（個別物件、生物、普通交談、採集和細部調查）。
- 中央：事件演出（共用對話框、選項、場景動畫和結果）。保留畫面直接點擊。

## 實作

`action()` 預設 `detail`；`sceneAction()` 使用 `scene`；`eventAction()` 使用 `event`。`splitSceneActions()` 將 scene 與 event 分配至下方，detail 分配至上方。`routeAction()` 沿用目的地名稱。上方調查列表排除已歸入下方的開場線索、微光、聲響及石門事件，但不移除其場景點擊入口。

目前選擇將開場劇情、特殊遭遇、部分委託與初次劇情互動分類為 event；後續依實測調整，並避免重複入口。保留原有劇情、時間、存檔與路線條件。

主頁三段 inline JavaScript 語法及三類分流測試通過；iPhone 版面與完整事件遊玩尚待實測。
