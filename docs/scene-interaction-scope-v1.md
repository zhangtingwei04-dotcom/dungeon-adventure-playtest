# 燈火核心系統｜場景操作分層 V1.0

確認日期：2026-11-26

## 介面規範

- 下方：主要行動（Primary Actions），控制當前場景整體行為，例如探索周遭、休息、等待（未實作的功能不新增按鈕）、前往已發現的地點。保留「調查／其他行動」作為開啟上方情境互動的入口。
- 上方：情境互動（Contextual Interactions），針對物件、生物、NPC、線索和特定事件。個別事件即使是主線，也屬於情境互動，不因 primary 標記而放入下方。
- 中央：事件演出（Event Presentation），共用對話框與場景動畫呈現行動、選擇及結果。玩家可直接點擊場景物件進入相同事件。

## 實作契約

`action()` 預設 scope 為 `detail`；`sceneAction()` 使用 `scene`；`routeAction()` 使用 `sceneAction()` 並從地點名稱建立目的地標籤。`splitSceneActions()` 是上下區共用分流規則。保留既有路線解鎖、時間、採集及劇情限制。上下區不代表強制先後順序。

## 驗收

檢查探索、移動、休息只在主要行動區；個別物件和 NPC 操作在情境互動區，場景點擊仍可使用。三段主頁 inline JS 語法編譯檢查及六項分類測試通過；手機實際版面仍需驗收。不要把尚未實作的等待功能視為已完成。
