# 燈火核心：八方向轉向 V1.0（苔棘鬃獸 V3.5 候選）
- creature_direction_v1.js 提供 plan(from,to,{speed,prefer,full})、sample(plan,ms) 及 mixPose(neutral,step,weight)。
- 方向 0–7，每格45°，0正面、2右側、4背面、6左側；最短路徑最多4步，180°平手可選方向；完整一圈為8步。速度每格450/275/180ms，180°為1.8/1.1/.72秒。
- 站立轉向使用各方向原地步態取樣，起收步權重逐漸變化；步態中轉向保留原動作計時，不重設相位。圖像不跨方向插值、疊加或拉伸。五套方向骨架和三套鏡像維持原樣。
- 這是離散八方向踏步轉向原型，不能宣稱真正連續骨架旋轉；各方向腿部透視不同，換圖時仍可能跳動。移動中的世界座標、景深位移、足點世界鎖定與完整動作混合未實作。
- 數值驗證：384組路徑，33312次路徑取樣，16組整圈，5025組同視角姿勢混合。最小蒙皮列間距2.193px。未進行實機美術驗收，正式戰鬥不修改。
