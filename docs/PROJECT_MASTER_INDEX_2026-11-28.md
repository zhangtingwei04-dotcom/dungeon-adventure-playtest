## 2. 遊戲方向與世界
固定第一人稱2D像素場景、手機橫式優先、場景點擊、對話選擇與回合制冒險；生活、生態、研究和戰鬥並重。主角是本世界居民，保有自己的記憶，在孤兒院長大、軍校出身，受校方安排前往城鎮獨自租屋；開場為城鎮。燈火會已篩選主角，派遣考察任務，完成後面談並邀請入會。原失憶與馬車開場已被新設計取代。[新版主角設定](design/city-opening-society-civilization-relics-v1-2026-11-28.md)；[舊版歷史設定](design/protagonist-origin-and-optional-past.md)。
「燈火是自己的錨點，照亮出自己的模樣。」心靈、意志、認知與存在為核心；世界認知扭曲形成異常，群體認知可能影響現實，傳說可能具現。燈火法是正常修習法；燈火會為特殊組織型異常，獨立於普通冒險者，秘密處理異常、設置地域燈火以降低異常及穩定認知。迷宮是已知最大異常；其他難以解決的異常存在。原初世界假說是內部研究方向，歷史覆寫、迷宮殘存、自穩、神明與傳說成因仍為假說。《世界的第一場夢》是傳說，不是已證實歷史。恆異、定界燈等暫名待定。傳奇人物與遺物、燈獸依錨點文件，不另增屬性。永夜人物稱號以錨點文件當前記錄「永夜伯爵」列索引；若後續確認改稱永夜爵，需同步修正文檔，爵位與職業不可混同。

## 2.1 玩家長期冒險方向：燈火會派遣與地域錨定（2026-11-28 更正）
使用者澄清：所指的先前冒險方向是燈火會派遣玩家前往各地設置燈火，而非重新安排開場劇情。本節取代V1.1對該句的誤解；後續使用者已改定城鎮開場及非失憶主角；原有馬車、森林、城鎮等素材與共用玩法保留，舊開場故事不再作新設計基準。
- 核心循環（正式入會後）：接受燈火會派遣→準備補給、裝備及燈火→前往未知地域→調查異常→尋找適合的設置位置→設置地域燈火→觀測異常及穩定狀況→回報燈火會。
- 主要方向：以旅途、異常研究與地域穩定推進長期冒險。燈火降低地域異常、維護世界認知；派遣不必皆以擊殺敵人為目標。必要時自行處理、封存或控制異常，無解異常可保持穩定。
- 地域變化候選：道路與生態逐漸穩定、旅人或冒險者得以進入、廢棄聚落可能重新有人居住。依遊戲時間及事件條件更新，不保證所有地域都恢復或所有異常都消除；不擅自設定數值、速度與獎勵。
- 隨著燈火會派遣與探索深入，玩家可能逐步抵達更遙遠的地域及迷宮，在未知處建立新的燈火據點。具體派遣順序、迷宮進入資格及燈火設置規則待設計。
- 保留非會員的普通生活、探索與冒險自由，不強迫入會。正式異常調查及燈火會派遣依會員資格開放。
此為使用者確認的長期冒險核心方向；完整派遣系統、設置地點、世界變化與遊戲數值均尚未實作。
