# 《迷宮盡頭的燈火》：紙娃娃穿著方式試驗 V1

日期：2026-11-23；狀態：**僅開發者總工作台測試，尚未安裝到正式遊戲**。

## 目的

在不重畫已核准的男／女 64×160 原底模、白布衣 V3、旅行長褲 V2、深綠披風 V2、附魔側包的前提下，讓上衣和下裝更自然地接合，並確保未來更換衣物不留下固定遮擋。

## 首階段實作（工作台）

每件上衣（chest 類別）針對男、女可以各自存 `wearMode`，並保留原本每片 `x`、`y`、`scale`、`z`：

- `tucked` / 紮入式：保持已確認原始 Z 的上衣在褲腰後，現有畫面不變。
- `untucked` / 自然垂放：**只**將正面主衣身的下擺按 64×160 畫布的 Y 範圍拆成上下兩個渲染區段：上段仍按照原 Z，較低的衣襬區段畫在已穿長褲之後；左右袖的位置和 Z 不動。截斷點暫定 Y≈85+衣身 Y（限制在 68–112），目前屬試驗參數，不是已驗收的最終遮罩。
- `outer` / 外罩式：將該件上衣各片於渲染時動態抬到長褲之上，披風保留獨立 Z 設定。這只是圖層模式，**沒有新增長袍衣襬圖片**。
- 以上在未穿長褲時不強制套用跨服裝的遮擋規則；原本圖層位置保持。

既有披風本來就是「後片在身體後、前片在衣服前」的包覆模式；本階段不重製披風或修改它的已核准 Z。其他非上衣類保持既有預設。

### 操作

- 工作台「角色裝備庫」→ 白色初始布衣 → 選男性或女性 → **上衣穿著方式**。
- 角色即時預覽下有三個一鍵比較按鈕：「紮入式（男女）」「自然垂放（男女）」「外罩式（男女）」。
- 在單一性別上改好後，也能選「將穿著方式套用至男女」。
- 初次快速展示連結：`developer-studio.html?tab=library&wear=untucked&v=wear-mode-p2`。此連結**僅切換畫面**，不會擅自改寫該裝備的座標、Z 或本機儲存值；在工作台實際按按鈕才會保存。

### 儲存、重設和兼容

- 工作台本機 `wearModes[assetId:gender]` 儲存於現有開發工作台設定，不碰正式遊戲存檔。
- 原 `dungeon-character-asset-library-v1` 匯出結構在 `genders.male/female` 旁增加 `wearMode`，老 JSON 欠缺這個欄位時自動退回 `tucked`，不刪除既有 X/Y/Z。
- 「恢復已確認服裝位置」／「重設全部位置」會還原既有用戶確認的 X/Y/Z，並將上衣穿著方式恢復至紮入式；「重設此圖層」只管當前圖層，避免意外重設整件衣服穿著方式。
- 玩家未確認新美術前，未更動正式 `index.html`、`assets/white_shirt_workbench_v3.js`、`assets/travel_trousers_workbench_v2.js`。

### 驗證與待驗收

- GitHub 回讀已確認 JS 語法。
- 模擬紙娃娃繪圖順序：紮入式 = 上衣→褲子；自然垂放 = 上衣上段→褲子→上衣下擺；外罩式 = 褲子→整件上衣。測試結果符合預期。
- **仍須 iPhone 直／橫式實際驗收**是否自然、下擺切口是否有直線、袖口或衣角是否互相遮擋。若不自然，應依現有原版白布衣的透明像素製作不破壞美術的局部遮罩；不要聲稱這已是最終完美的自動遮擋系統。
