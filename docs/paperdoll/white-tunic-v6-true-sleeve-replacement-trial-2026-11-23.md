# 《迷宮盡頭的燈火》白色上衣 V6：真正替換短袖的試驗

日期：2026-11-23；狀態：**只在開發者工作台試穿，尚待 iPhone 驗收**。

## 使用者要求
- 不喜歡 V4「短袖再接長袖」造成明顯接縫、顏色不同及袖子細長。
- 回到先前偏好的較長袖設計，以原始 V3 白布衣的肩部外形及暖灰米白色票為基礎，只向下延長袖身，袖口停在手掌上方。
- 正式遊戲與已確認的披風、長褲、頭髮、男性披風 Y -6、女性長褲腰部 X 0/Y -5 等設定均不能受到影響。

## 真正替換而非疊加
1. `assets/sleeve_replacement_workbench_v6.js` 保存四片 64×160 RGBA 的男女左右新袖，依序合併為 256×160 透明圖集。上半段是已確認 V3 來源原生像素；手肘以下依其配色延長。並未更動任何原版 V3 圖檔。
2. `developer-studio.html` 加入 V6 專用試穿旗標 `sleeveReplaceModeV6`（預設關），會保存於既有工作台本機設定。
3. 為避免歷史 V3 的 `front/side/back` 命名與圖集實際順序不一致，執行階段測量三張 V3 圖層中心區域的 alpha，找出「真正主衣身」是哪一片。V6 開啟後只保留這張原 V3 衣身，隱藏舊兩張短袖片，再以 Z43/44 繪製新袖。
4. 舊 V4 **疊加式**長袖已判定失敗，進入 V6 或切回 V3 時都強制隱藏；不會刪除舊圖檔或用它覆蓋 V3。
5. 披風 V4/V5 的手臂像素補畫遮罩已追加新 V6 袖片的 alpha 作排除條件，減少裸膚覆蓋袖口。
6. 工作台按鈕「試穿長袖 V6｜真正替換短袖」與「恢復原版短袖 V3（男女）」可切換。舊上衣、座標、Z、穿著方式仍可還原；重設服裝位置會關閉 V6。

## 驗收與限制
- 此 V6 是 64×160 原生像素圖層試驗，**尚未經實際 iPhone 截圖確認衣服／披風／手臂是否完全自然**，不得視為正式批准。
- 已通過 PNG 256×160 尺寸和 CRC 檢查、素材與工作台 JS 語法及 GitHub `main` 回讀；正式 `index.html` 無修改。
- 如出現手臂被蓋住、胳膊過細或肩縫不自然，直接按「恢復原版短袖 V3」回退，調整新袖片，不去改原始角色。
- 若自訂上衣把三張 V3 衣身／袖片合併成單一完整圖檔，這個測試版依中心 alpha 判斷衣身的規則可能不適用，需另行分離圖層。

## 修正：V6 袖片先前無法獨立拖曳（2026-11-23 晚間）

使用者實測回報「好像移動不了」。原因是 V6 雖然可顯示於預覽，但先前完全繞過工作台素材選單與 pointer drag 系統；兩袖共用主衣身 `transforms`，無法各自調整。

這次已修正工作台：
- 新增正式可選取的 **`starter_sleeves_v6` 工作台裝備**（只限工作台，**不是正式遊戲新裝備**），男女各兩個獨立圖層：`side` = 畫面左袖、`front` = 畫面右袖。
- 原 64×160 V6 圖集不變，映射到四個內建圖源，各自可拖曳／輸入 X、Y、縮放、Z，各性別可不同。
- 舊 V3 主衣身保留；V6 啟用時不再繪製原短袖，直接透過工作台通用 Z 排序繪製 V6 新袖。
- 對深綠披風的補畫皮膚遮擋，已改成讀取 V6 各袖自己的圖檔與座標。
- 「試穿長袖 V6」會自動選取可編輯的 V6 袖片；「恢復原版短袖 V3」還原原始上衣。重設服裝位置關閉 V6 並恢復原版預設。
- 同一 V6 工作台連結加新的快取參數，確保手機載入更新的 JS。

目前已驗證 GitHub main 原檔回讀、JS 語法、圖源映射、兩性四片的獨立 transforms、pointer 事件與回退路徑。**仍需 iPhone 實機拖曳確認**。未修改原 `index.html` 或其他正式裝備。
