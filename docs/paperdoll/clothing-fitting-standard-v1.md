# 《迷宮盡頭的燈火》紙娃娃服裝製作標準 V1

- 決策日期：2026-11-23
- 適用專案：**《迷宮盡頭的燈火》**（不可與《鱗片與種子：地下生態物語》或歐姆計劃混用）
- 狀態：**使用者確認的長期製作原則**；個別素材仍須獨立驗收，不能因規則已定而視為已完成或已正式安裝。

## 核心原則（最高優先）

**先自然，再拆分；先配合角色底模，再製作裝備素材。**

1. **固定已核准底模**：男性、女性各自使用遊戲目前的 64×160 像素原始角色素材，不因新衣服改動頭部、身體、肩膀、手臂、手掌、姿勢、比例、膚色或既有內衣。
2. **先製作穿著完成圖**：分別將完整服裝直接對齊男、女角色原有上半身，先確定肩線、袖型、袖口、胸口、腰線與輪廓自然；不再先各自生成獨立袖子後勉強拼接。
3. **袖子由手臂決定**：衣袖角度、接縫與袖口必須跟隨該性別實際手臂方向；左右長度與視覺量感要協調，**不要求完全鏡像**，不得為追求鏡像而造成袖口與手臂錯位。
4. **完成穿著驗收後才拆分**：普通正面上衣拆成（a）主衣身（b）左袖（c）右袖；男性與女性**各一組**，共六個獨立圖層。特殊服裝可按實際遮擋需求額外分層，不能機械套用三片規則。
5. **只有正面**：目前上衣只需要正面視角，不生成背面服裝視角；服裝的「前後遮擋關係」不等於要畫背面衣片。
6. **真正透明**：各片為透明 PNG，與角色共用 64×160 原生座標／定位；領口中間不得畫入背面內襯或其他多餘背面布料，應讓原角色脖子／內衣在該處自然露出。拆分後不能有重複袖口、雙層黑邊或殘留遮罩。
7. **保留初始內衣**：米白背心是基本內衣，不是正式上衣裝備、不占上衣槽；上衣卸下後內衣仍顯示。
8. **分層實測才算完成**：在開發工作台測試（a）內衣（b）只穿新上衣（c）上衣＋已核准披風／既有背包；檢查雙手是否被遮蔽、左右袖是否對齊、男女底模是否原樣、穿脫是否正常及 64×160 像素是否失真。以 iPhone 橫式預覽驗收為重。
9. **先工作台後正式版**：新衣服先在獨立工作台驗收；未經使用者確認，不可覆蓋既有正式素材或假稱已安裝到遊戲正式裝備欄。

## 適用範圍

預設適用於外穿上衣、襯衫、外套、長袍、輕甲、護甲、披風內搭以及其他需要與角色手臂貼合的服裝。簡單內衣、項鍊、胸前裝飾等若無手臂貼合要求，可直接分層，不必先做全身穿著完成圖。披風或特殊垂墜服飾另依其遮擋需求劃分層次。

## 目前案例：白色初始布衣

- 色彩：白色／暖米白，短袖、胸前系帶，正面領口透明。
- 使用者已指出之前試穿中**袖子與手臂方向不合**，是必須先修復的問題；**不能把舊的鏡像袖素材直接視為驗收通過**。
- 推進順序：直接使用現有男女角色底模各自畫完整穿著版 → 修正手臂與袖口方向、黑邊和遮擋 → 使用者確認外觀自然 → 各自拆出主衣身／左袖／右袖 → 工作台測試 → 核准後才裝正式遊戲。
- 既有開發者總工作台：`developer-studio.html`；原有試穿與分層結果僅供參考，下一次修改必須依此標準重驗。

## 恢復開發檢核

下次繼續製作服裝時，先閱讀此文件、檢視 main 最新正式底模和現有工作台狀態，再實際動手；不要只依照舊示意圖猜尺寸。若使用者未另外變更規格，以上就是服裝製作的預設標準。

## 可重複使用的像素數據（2026-11-23）

- [男女底模實測座標與上衣設計錨點 JSON](clothing-fit-data-v1.json) 已納入專案。
- 座標原點左上，X 往右、Y 往下，尺寸固定 64×160 px；資料以原始身體及米白內衣 PNG 的 alpha≥64 像素為依據，包含男女逐列輪廓抽樣與袖口起始參考值。
- **請區分**：JSON 的 `measured` 是實測像素；`draftTargetForWhiteStarterShirt` 是可微調的設計初值，並**非**已完成或使用者核准的貼合座標。
- 未來每次要製作新上衣，請先讀取 JSON、檢查原始底模版本 SHA，再在底模上畫完整穿著圖，經確認後才拆成男女各三層。底模若更換，應重新量測，不得無條件沿用舊數據。
