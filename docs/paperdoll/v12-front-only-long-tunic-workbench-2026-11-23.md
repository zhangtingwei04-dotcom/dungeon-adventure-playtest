## 使用者明確要求
- 原始 **V3 白色短袖**完整保留，不得覆蓋或修改其圖檔／座標。
- 新長袖與 V3 作為**兩件獨立服裝**切換。
- 新長袖只需 **衣身正面＋畫面左袖＋畫面右袖**；**不要背面圖層**。
- 左右袖的圖層在衣身正面後方，且男女左右袖位置皆可獨立調整。
- 使用者不滿意 V10 的破碎裁切外觀，不應把 V10 視為已核准遊戲服裝。
- 長袖先於開發者工作台試穿，不得未經驗收就上正式遊戲。

## V12 實作
- 工作台：`developer-studio.html?tab=library&frontSleeves=12`
- 素材：`assets/long_tunic_front_sleeves_v12.js`
- 來源：最近一批經使用者回覆「好，可以」的六張生成透明服裝元件；原始大圖尺寸、方向不一致，已對照已量測的 64×160 身形定位，重新壓合至原生透明袖形與上衣輪廓，避免縮圖留下透明缺口。
- 六張透明 PNG：`maleV12Front`、`maleV12Left`、`maleV12Right`、`femaleV12Front`、`femaleV12Left`、`femaleV12Right`；儲存為 384×160 含 alpha 的 PNG 圖集，切出每張 64×160。
- 新增兩個工作台服裝 ID：`starter_tunic_layered_v12`（僅正面），`starter_tunic_layered_v12_sleeves`（左右袖）；**沒有任何 V12 back 圖層**。
- 兩袖 Z38／Z39、衣身正面 Z42；與原已確認衣服同座標系。男性預設 X=-1、Y=-1；女性 X=0、Y=-1，均 scale1。
- 支援工作台「V12 男女試穿」、「回到 V3 短袖」、「V12＋披風」，且圖層原生坐標可單獨拖曳。
