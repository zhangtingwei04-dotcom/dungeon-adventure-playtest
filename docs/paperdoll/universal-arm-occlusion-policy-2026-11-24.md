# 《迷宮盡頭的燈火》｜通用手臂可見性規則 V1

日期：2026-11-24
狀態：已加入開發者工作台，**iPhone 畫面仍待驗收**；正式遊戲 `index.html` 未修改。

## 使用者需求（長期規則）
> 以後替換其他衣服時，手臂、袖口和手掌都不能被披風前片不正常遮擋。

此需求不是「所有外套永遠不得遮到任何手臂」，而是確保**披風在肩頸、扣環及上臂正常覆蓋，肘部以下屬於角色目前穿著的手臂與手掌應保持可見**。實際前後關係仍應依服裝種類與該披風的角色設計作調整。

## 實作
- 通用模組：`assets/arm_visibility_policy_v1.js`，`DungeonArmVisibilityPolicyV1`。
- 呼叫入口：`developer-studio.html`。
- 原流程：在披風前片之後固定補畫部分原始裸手臂皮膚；遇到長袖，會把長袖遮住、手掌只露出一角。
- 新流程：先在 64×160 原生像素空間渲染**角色原始 Body + 目前真正顯示的上衣／袖片／手套**（使用實際 X/Y/scale），形成手臂佔用遮罩；再僅於肘部至手掌區域，把披風**前片**對應像素設透明，讓既有的衣服及手掌透出，不在披風上補畫裸露皮膚。
- 標準區域：目前基於原男女底模的 Y74–102，逐列限制 X 範圍，只修真正有手臂/衣服輪廓的像素；肩頸、胸口金色扣環、披風主體、下擺不改。
- **不修改任何原版 PNG**：遮罩作用於每次繪製的臨時 Canvas。兩性、各服裝都沿用相同規則。
- 共享 `currentGarmentActive(asset, gender, layer)`：衣服實際繪製與遮罩都使用這份規則，避免 V3、V9、V10、V12、V13 試驗圖不小心重疊；`getVisibleArmGarments` 按 `slot='chest'/'hands'` 取得目前服裝，不必每件新上衣硬編 ID。
- 披風類（`slot='outer'` 且有 back/front 圖層）在前層採用此通用規則；其他種類的外衣若需要遮住手臂，應另外依設計定義遮擋規格，不能盲目套用。
- UI 「披風手臂保護」預設開啟；歷史「V5 補畫皮膚」保留可切換比較，但**不是預設**。
- V13 長袖＋披風網址：`developer-studio.html?tab=library&naturalLong=13&cloak=1&v=arm-policy-v1`；明確開啟此網址會選擇新規則，排除舊 V5 模式。

## 未來其他衣服的規範
1. 所有新上衣、袖片及手套提供完整透明 PNG，使用底模原生座標。
2. 衣身正面與左右袖獨立、袖子在衣身正面後層；必要時把袖子明確標為 arm region。
3. 工作台加入素材後，放在 `chest` 或 `hands` 類別並設定實際位置即可接受通用披風手臂保護；不應每件都寫額外皮膚補畫程式。
4. 有特殊盔甲或寬袖時，可為該服裝建立身形專屬輪廓/遮擋規則，而不能保證通用原始 Body 走廊完全精準。
5. 僅在 iPhone 實際試穿驗收後，才考慮同步到正式遊戲。
