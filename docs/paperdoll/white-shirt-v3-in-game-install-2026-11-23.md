## 使用的來源與位置
- 六圖層：`assets/white_shirt_workbench_v3.js`，384×160 sprite sheet，男／女各三張 64×160（主衣身、畫面左袖、畫面右袖）。

- 男：全部衣服圖層 x=-1、y=-1、scale=1。
- 女：全部衣服圖層 x=0、y=-1、scale=1。
- 原始 body、tank、shorts、髮型、表情等維持不變；初始米白背心仍是內衣。
- 沿用正式既有 `equipmentV1.chest='starter_tunic'`、已有「裝上／脫下」操作及存檔，不新增存檔欄位。
- 背包、披風、長褲等既有裝備不改；披風仍原本核准之男 -8px、女 -6px 前片座標。
- 若與披風合穿，原始手臂前景遮擋改為只復原較外側下臂，避免擦掉布衣輪廓；**披風單穿**原本的裁剪範圍保持不變。
- 私密場景 `bath`、`dressing` 不畫上衣。
- 預留視覺回退參數：`?shirt=off` 只隱藏新白布衣外觀（不脫裝備、不影響存檔）。`?cloak=off` 只隱藏披風外觀，方便看清白布衣。
- 若要避免正式遊戲存檔變動，可用 `?dev-preview=1&cloak=off` 在獨立開發存檔遊玩。
