# 《迷宮盡頭的燈火》｜完整獨立米白長袖 V9 工作台試穿

日期：2026-11-23
狀態：**工作台試穿（未獲 iPhone 視覺驗收），沒有替換正式遊戲素材**。

## 使用者的明確要求
> 「試試看，另一個短袖的就保持原狀，這次長袖的一起」

因此採用 **兩件獨立的衣服**，不是以長袖覆蓋／改寫 V3：
- 原本 **白衣 V3 短袖**：`starter_tunic`，三張原有透明圖層完全保留，座標不變。
- 新版 **米白系帶長袖 V9**：`starter_long_tunic_whole_v9`，男、女各 **一張完整 64×160 透明 PNG**。衣身＋左右袖合成單件；該件拖曳時全衣一起移動。
- 原本 V4/V6/V7 袖子試驗保留作歷史對照，但 V9 啟用時不會一起繪製。

## 美術來源與定位
- 以最新兩張使用者在對話中展示的透明衣服生成圖為來源，男性用「象牙白系帶襯衫與獨立長袖套裝」，女性用「象牙色蕾絲束帶長袖套裝_spritesheet」。
- 兩張大型概念素材原本並非遊戲底模原生比例，因此依使用者先前確認的男女手臂輪廓、V3 原衣位置、肩部與袖口方向，**縮放／裁切**後組合到各自 64×160 畫布，保留真透明 alpha。
- 組合後男、女素材的非透明覆蓋約 X6–57、Y52–93（圖源原生座標）；預設男性 x-1/y-1、女性 x0/y-1、z42。
- 縮至 64×160 可能讓高解析生成圖的細緻皺褶失去部分細節；僅為試穿稿，不保證符合最後美術品質。若接合仍不自然需回到素材修正，不應只改 z。

## 開發者工作台
- 新素材來源：`assets/whole_long_tunic_trial_v9.js`。其中的 128×160 索引色 PNG 含透明通道，男女各裁切成獨立 64×160。
- `developer-studio.html` 的角色裝備庫新增「米白系帶長袖 V9｜完整獨立上衣」，以及三個按鈕：
  - 「新長袖 V9｜整件試穿（男女）」
  - 「回到原版 V3 短袖（男女）」
  - 「新長袖＋披風」
- 新長袖打開時，**V3 只停止顯示，原 V3 PNG 與座標、短袖 z、圖片及存檔均不被改寫**。關閉 V9 立即還原 V3 短袖。
- V9 自己可移動 x/y、縮放與 z，男女分開記錄。V9 也可以選擇「紮入／自然垂放／外罩」穿著模式。
- 披風的既有手部補畫遮罩已支援讀取 V9 的 alpha，減少把皮膚補在袖子前面的情況。
- 「重設服裝位置」關閉 V9，回到先前的已確認位置。
- 本機只記錄工作台試穿狀態，不修改 `index.html`、遊戲正式存檔、玩家身形、已確認披風／長褲／背包。

## 驗證
- 已通過 128×160 圖集 PNG 段 CRC、真透明 alpha、JS 語法、兩套衣服互斥圖層及 reset 與回退路徑檢查。
- 原始 V3 短袖圖源 SHA 完全未變。
- **仍需使用者 iPhone 實際驗收**：肩膀自然度、袖口與手掌接合、衣身寬度、披風遮擋與白色衣服立體感。
