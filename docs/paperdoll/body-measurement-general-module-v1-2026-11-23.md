## 自動測量範圍

從透明 PNG 的每個 Y 橫列讀取 alpha，並只在所選區域（手臂／軀幹／腿）尋找連續輪廓像素。15 個預設位置：

- 左右手臂：肩膀／手肘／手腕（6）
- 軀幹：上胸／胸部／腰部（3）
- 左右腿：大腿／膝部／小腿（6）

按「自動掃描所有部位」可立即建立 15 筆起始候選值。使用者可調整原生 Y、左邊界 X、右邊界 X，按「確認此列」將資料標為已複核。**這不是骨架／語意關節辨識**：在手臂接觸胸部、腿部相連、姿勢不同、半透明邊界等情況，候選值可能錯誤；結果附 `ambiguous` 和 `reason`。

掃描器只提供前視像素輪廓；不推導背面、人體厚度、衣服鬆量，也不保證任意姿勢的準確度。衣服仍應使用原身體圖與畫面測試檢查。

## 身形管理
- 內建 `male_body_v1`、`female_body_v1`，讀取遊戲已核准的原始 Body PNG。
- 未來可匯入新的透明 PNG（原生寬 32–512、高 64–512 px，檔案不超過 5MB），自訂 `bodyId`；不同尺寸不被拉伸成 64×160。
- 自訂身形使用 IndexedDB 儲存圖像於**當前裝置及瀏覽器**；測量數據按 bodyId 隔離於 localStorage。不能假設跨裝置雲同步；可下載 JSON 備份。IndexedDB 不可用時，僅保留當次使用中的圖片。
- `dungeon-body-measurement-v1` JSON 含 bodyId、畫布原生尺寸、部位、地標、Y、左右 X、像素寬度及 reviewed/ambiguous 等資訊。
- 先前使用者提供的 12 組男女手臂量測已內建為「初次使用」基準資料；原始肩膀標記仍保留可能與胸口連結的歧義，Y83 仍須確認是否為真正袖口終點；**不會覆寫後續手動修改**。

## 安全界線
- 本模組是開發者總台的獨立分頁與 iframe，**不會寫入**遊戲正式存檔、服裝坐標、玩家裝備、角色底模或 GitHub 正式遊戲。
- 目前只產出量測結果，不自動生成／安裝衣物。
- V3 白衣、V6/V7 袖子、既有披風、褲子、頭髮的圖檔與位置未更改。
- 若要替換 V8 袖子，仍需按既定流程：先完整試穿預覽 → 使用者同意 → 拆透明 PNG → 工作台實測 → 再決定是否裝正式遊戲。
