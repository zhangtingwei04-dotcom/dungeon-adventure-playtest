# 白色初始布衣 V4｜獨立長袖試穿

日期：2026-11-23。專案：《迷宮盡頭的燈火》。

## 範圍與素材

依使用者授權，將最近單獨生成的兩隻米白色袖子，縮放／貼合目前 64×160 男女角色，各保留畫面左側和右側的獨立 RGBA PNG；四片以 256×160 圖集嵌入 `assets/long_sleeves_workbench_v4.js`，每片依原生座標還原到 64×160，不需另外縮放。

- 男性左袖 X9..19、Y66..84；右袖 X44..54、Y66..84
- 女性左袖 X10..20、Y65..83；右袖 X43..53、Y65..83
- 工作台位移保留既定上衣錨點：男性 X-1/Y-1；女性 X0/Y-1，scale=1。
- 新袖子的 Z 為 43 / 44（高於原上衣 V3 的 40–42，低於褲腰 52 與披風前片 80）。
- 生成圖片本身不是原生像素素材：由高解析透明 PNG 縮放至 64×160，必須以實際 iPhone 試穿效果驗收，而非宣稱達到最終完美美術。

## 安裝方式

在 `developer-studio.html` 新增獨立內建工作台裝備 `starter_long_sleeves_v4`；兩個圖層分別為 `side`（畫面左袖）與 `front`（畫面右袖）。開啟「試穿新長袖 V4（男女）」後顯示；「恢復短袖 V3（男女）」可立即回退。兩性 X/Y/Z 可自行微調，工作台設定可儲存與匯出 JSON。**沒有覆蓋白衣 V3 原片，不改動正式 `index.html` 或玩家存檔。**

目前披風 `starter_cloak` 的手臂像素還原採特殊處理；新增袖子的 alpha 已被加入還原遮罩排除條件，避免手臂皮膚畫到袖子前面。未穿原上衣時，長袖 V4 不會單獨顯示。
