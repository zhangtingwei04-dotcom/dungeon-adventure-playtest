# 白色初始布衣 V3：最新生成圖直接試穿

日期：2026-11-23
進度：**GitHub main 開發者總工作台已安裝最新生成白布衣 V3（獨立試穿）**。未安裝到正式遊戲，iPhone 畫面仍需使用者實際驗收。

## 本次製作

1. 使用最新生成的男女**完整正面**白布衣，不使用獨立生成的零散袖子硬套：
   - 男性來源：奶油色像素中世紀繫帶上衣.png
   - 女性來源：復古像素奶油色繫帶冒險上衣.png
2. 以 [底模測量數據](clothing-fit-data-v1.json) 和已有的男女 64×160 像素角色座標為準：
   - 男性整衣相對位置：原生畫布 x=10、y=51，縮為 44×40 像素。
   - 女性整衣相對位置：x=11、y=52，縮為 42×39 像素。
   - 註：這是「放上工作台實驗」的位置，不是已確認的永久版型。袖口仍應在真實 iPhone 顯示核對。
3. 整件衣服**先對齊，再拆**為每性別三片 64×160 透明圖層：front core、screen-left sleeve、screen-right sleeve。
4. 程式驗證：每個性別的三個圖層重新組合，其像素與這次縮入座標的整件上衣相同；兩個來源各自獨立，未強制左右鏡像。
5. 素材：assets/white_shirt_workbench_v3.js，六個 64×160 部件，384×160 透明 PNG 圖集（索引式 PNG 含透明通道）。
6. 工作台：developer-studio.html，入口 `?tab=library&shirt=3&v=20261123v3`。可測「只穿白布衣／白布衣＋披風／脫下白布衣」，進入 V3 入口避免 V1／V2 本機匯入圖覆蓋新版本，但不刪除使用者資料。
7. 正式遊戲 `index.html`、原始底模、米白內衣、存檔未修改。舊 V2 js 仍保留，可回溯。

## 尚需驗收

- 兩性肩膀與手臂向外下方的角度，尤其袖口到裸露手臂的黑邊接合。
- 胸口與腰線有無被長袖／披風圖層遮住。
- iPhone 橫式顯示後才可判斷是否正式採用；若不合，回到完整上衣版調整形狀，再拆層。
