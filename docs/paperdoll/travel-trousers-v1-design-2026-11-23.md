# 《迷宮盡頭的燈火》旅行長褲 V1｜男女底模試穿設計

設計日期：2026-11-23
狀態：**初版設計完成，六片 64×160 透明像素素材已加入獨立工作台；尚未核准正式遊戲裝備美術。**

## 設計

- 款式：深暖棕色中世紀旅行布褲；輕量直筒、膝部少量自然摺痕、踝上反摺褲腳。
- 腰部：窄皮革腰帶、古銅金色簡單扣具；可被白色旅人布衣自然覆蓋，不用獨立穿過身體。
- 男／女各自使用原始底模腿型，沒有強制用同一張尺寸縮放，保留腳踝及腳掌做後續長靴素材。
- 畫布：每片 64×160、透明 RGBA、前視圖；原點左上，X 向右、Y 向下。
- 色彩：邊線 #2E2726、布料主色 #695341、陰影 #44352F、亮部 #806A52、縫線 #473B34、扣具 #D1AD64。
- 完整畫好每個性別的長褲後，分為三片：腰臀主片、畫面左褲腿、畫面右褲腿。切片之後重新合成與完整版本像素一致。

## 驗收待辦

1. 在 iPhone 橫式看兩個性別的腰臀比例與褲管角度，避免兩腿一樣粗或站姿不自然。
2. 穿白布衣時檢查下擺是否遮住腰帶的錯誤位置，以及褲腰是否露出不自然黑邊。
3. 搭配披風時檢查褲腳和包包的位置。
4. 獲使用者確認後再正式接入 `starter_trousers`；在此之前不得說正式裝備已裝好。
