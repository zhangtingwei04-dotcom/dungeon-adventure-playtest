# 《迷宮盡頭的燈火》V8 長袖開發｜手臂逐像素對照與驗收前置作業

日期：2026-11-23。**目前僅分析，不生成或裝入 V8，不修改正式遊戲**。

## 資料來源

- `assets/cloak_workbench_bases_v1.js`: 正式遊戲使用的男女 64×160 Body 原始 PNG。
- `assets/white_shirt_workbench_v3.js`: 白衣 V3 兩性衣身／左右短袖分層透明圖集。
- `assets/sleeve_replacement_workbench_v7.js`: V7 左右長袖 64×160 透明圖集，屬於尚未驗收的試驗版。
- 使用者提供 21:01 iPhone 工作台實際截圖（V7 袖子顯得筆直、厚重）。

## 已有資料與原因

- V7 先前製作時，肩部沿用 V3，但手肘以下採用固定的斷面寬度序列延長，**未先從原始 Body 提取逐列手臂輪廓**。這是其「布管」觀感的可能原因，仍需和實際角色截圖交叉核對。
- V7 製作記錄中，男袖大致延到原生 Y89、女袖到 Y88（還需在工作台計入已保存的 Y -1）。
- 只根據 `Body` 的 alpha 並不能百分之百判斷手部：底圖還包含軀幹和大腿，因此靠近腰部的位置應與手掌區分；不能把大腿皮膚誤當手臂。之前披風遮罩已發生此錯誤。

## 新增獨立逐像素測量工具

`arm-fit-diagnostic.html`

https://zhangtingwei04-dotcom.github.io/dungeon-adventure-playtest/arm-fit-diagnostic.html?v=1

提供：
1. 男／女原始底模、V3 原短袖、V7 長袖三種對照視圖，以及 V7 + 手臂候選輪廓疊圖。
2. 原生 Y=58、62、66、70、74、78、82、86、90、94、98、100 的左右側 alpha 範圍與 V7 寬度，用實際資料計算，不由人手填數字。
3. 每隻手臂數值以畫面左／右區域分開；貼合座標男 X -1/Y -1、女 X 0/Y -1。
4. 複製測量 JSON，作為後續 V8 修正和回歸驗收基準。

## 下一個 V8 圖層的前置條件

- 四隻袖片必須依各自對照資料製作，**不可只複製鏡像或用通用固定寬度**。
- 先定義肩膀、手肘、手腕、手掌邊界與「衣身—袖子」覆蓋順序；視覺上必須沒有第二道短袖接口。
- 直接沿用已確認 V3 配色與陰影，不修改衣身、領口、綁帶、腰部、背包或已核准披風。
- 先在聊天中顯示完整男女試穿供使用者核准；核准後再製作 64×160 的四張獨立透明圖層。
- 工作台試穿時檢查：左／右袖可個別拖曳；穿／脫披風無膚色穿透；脫下上衣袖子同時消失；一鍵還原 V3。
- 手機實機檢查自然度，沒有通過前不可更動正式 `index.html`。
