# 防風披風 V3｜正面九部件製作與試穿紀錄

日期：2026-11-24  
專案：迷宮盡頭的燈火  
狀態：使用者已確認正面素材設計；開發平台試穿草稿，尚未通過 iPhone 穿戴驗收。正式遊戲原版 V2 保留。

## 來源與設計決定
- 沿用使用者確認的米白毛領、深綠布料、金色滾邊、圓形金扣、植物刺繡。
- 所有部件以角色正面穿戴為準；不混用側面或背面外觀。後方披風使用正面所見深色內襯。
- 保留男女既有 64×160 原生底模、頭髮、頭部及脖子像素。前毛領左右分離，中央透明，扣環可獨立下移。
- 袖口、前臂、手掌及側包需保留既有圖層，禁止為披風重繪裸手臂。

## 製作方法與資料來源
1. 確認原始外觀並拆分九個可見部件、另製作 32/24 px 圖示。
2. 將正面拆分素材縮小至原生像素尺寸；清理背景與領口，組成 102×53 的 48 色索引 PNG 圖集。圖集已嵌入 windproof-cloak-front-preview.html；開發平台沿用同一圖集與裁切矩形，不重新生成。
3. 以透明 64×160 canvas 還原每一個圖層，保持一個固定座標原點。男女共用原圖，但可各自微調 X、Y、scale、Z 和顯示。
4. 身體後方圖層先繪製，前方披肩、毛領、扣環後繪製。前方採既有通用手臂像素遮擋策略，不補畫裸皮膚。
5. 在開發平台選「防風披風 V3｜男女試穿」，原 V2 暫時隱藏。使用者核准後才考慮正式裝備替換。

## 待驗收
- 男女脖子、下巴、鎖骨與毛領是否合理，扣環是否需下移。
- 左右肩披與各式短袖／長袖／外罩式上衣，以及手套、側包、長褲的疊圖。
- 長襬是否露出足夠、黑邊是否重疊，披風是否過窄或比例不自然。
- 圖層各自調整、JSON 匯出及重載、脫下及切回原 V2；確認 iPhone 橫式實際效果。
- 核准最終座標、保留版本與來源後，才進入正式遊戲。
