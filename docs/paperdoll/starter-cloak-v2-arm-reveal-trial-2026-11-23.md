# 深綠金邊披風 V2：前臂內側遮擋修正（試驗）

日期：2026-11-23
範圍：僅 `developer-studio.html` 工作台，**不修改正式 `index.html`、存檔、原 64×160 角色底模、披風透明 PNG、衣服座標或 Z 值**。

## 問題與設計

使用者從 iPhone 截圖觀察：披風前片似乎遮住左右前臂靠身體內側的局部。工作台原本在穿著白色上衣時用兩條矩形遮罩還原手部，過於窄：
- 左側 X 0–19，右側 X 44–63，Y 76–101。
- 未穿上衣時：X 0–23 和 40–63、Y 70–101（本次不變）。

**本次試驗只作用於 `starter_cloak`（深綠金邊披風 V2）**，不綁定其他未來披風。

新版在穿白衣時：
- 男性：左 X 0–23，右 X 40–63，Y 76–101。
- 女性：左 X 0–22，右 X 41–63，Y 76–101。
- 將原版身體、內衣和白色上衣的袖片在局部遮罩內重疊還原，盡量避免披風覆蓋前臂／袖口交接；沒有生成任何新皮膚或布料圖。
- 由於工作台支援每件裝備手動 Z 排序，還原前臂必須排在本件披風前片的 Z 之後（`max(90, cloakFrontZ + 0.5)`）。
- `CLOAK_ARM_REVEAL_TRIAL_IDS=['starter_cloak']`，未來其他披風可各用不同遮擋設定。

## 試穿與比較

在角色裝備庫預覽下新增「披風前臂修正：開／關（舊版對照）」；可同一畫面查看男女，按鈕隨本機工作台設定保存。新修正預設開啟；舊版對照恢復完全相同的原有前臂裁切範圍。

https://zhangtingwei04-dotcom.github.io/dungeon-adventure-playtest/developer-studio.html?tab=library&cloakArms=1&v=cloak-arm-reveal-trial-v1

`cloakArms=1` 會暫時顯示男女上衣、長褲及這件披風，並啟用新遮罩，不覆寫先前保存的座標與 Z；需在手機實際檢查。若發現新裁切會露出多餘皮膚或遮住袖緣，先按「關（舊版對照）」回退，並依截圖精修輪廓。
