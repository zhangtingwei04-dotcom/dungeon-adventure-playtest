## 問題與設計

使用者從 iPhone 截圖觀察：披風前片似乎遮住左右前臂靠身體內側的局部。工作台原本在穿著白色上衣時用兩條矩形遮罩還原手部，過於窄：
- 左側 X 0–19，右側 X 44–63，Y 76–101。
- 未穿上衣時：X 0–23 和 40–63、Y 70–101（本次不變）。

**本次試驗只作用於 `starter_cloak`（深綠金邊披風 V2）**，不綁定其他未來披風。

新版在穿白衣時：
- 男性：左 X 0–23，右 X 40–63，Y 76–101。
- 女性：左 X 0–22，右 X 41–63，Y 76–101。
- 將原版身體、內衣和白色上衣的袖片在局部遮罩內重疊還原，盡量避免披風覆蓋前臂／袖口交接；沒有生成任何新皮膚或布料圖。
- 由於工作台支援每件裝備手動 Z 排序，還原前臂必須排在本件披風前片的 Z 之後（`max(90, cloakFrontZ + 0.5)`）。
- `CLOAK_ARM_REVEAL_TRIAL_IDS=['starter_cloak']`，未來其他披風可各用不同遮擋設定。
