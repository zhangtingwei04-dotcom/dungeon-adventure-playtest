# 《迷宮盡頭的燈火》開發者工作台：每件裝備獨立前後層級 Z（V1）

- 日期：2026-11-23
- 已實作：`developer-studio.html` 角色裝備庫，男女、裝備、部件各自有獨立 Z；所有內建、自訂部件走同一排序渲染。
- **尚未修改正式遊戲 `index.html` 或其紙娃娃穿戴規則**。實際 iPhone 介面操作仍須使用者驗收。

## 用法

在「角色裝備庫」選擇裝備 → 性別 → 具體部件 →「前後層級 Z」。數字越大越靠近視線，可直接輸入 0–140，或點「前移一層 +1」「後移一層 -1」，亦可從快速層級選單選定常用位置。X、Y、Scale 仍完全獨立。

同一件褲子「褲腰」「畫面左褲管」「畫面右褲管」可以各自設定前後；衣服與褲子也能互相覆蓋。男女可以有不同的 Z。自訂衣服同樣支援。原來 `back` 指右袖／右褲管的歷史欄位名稱，並不強制渲染在後層。

## 初始 Z 座標（越大越前）

| 角色／服裝部件 | z |
|---|---:|
| 披風後片 | 10 |
| 原頭部底模 | 20（固定） |
| 原身體、短褲、米白背心 | 30、31、32（固定） |
| 白色上衣 V3 畫面左袖、右袖、主衣身 | 40、41、42 |
| 旅行長褲 V2 畫面左褲管、右褲管、褲腰／皮帶 | 50、51、52 |
| 原版旅行側包正面 | 70 |
| 披風前片 | 80 |
| 披風下露出的原手掌 | 90（固定的原手／前臂遮擋修復） |
| 男性眉、眼、嘴 | 100、101、102（固定） |
| 原版頭髮 | 120 |

其他未定裝備使用依分類／圖層推導的預設 Z，不代表美術已完成。移動任何部件到 z>90 可以畫在手掌前面。頭髮的 Z 也可調，但需注意臉部遮擋。

## 儲存和相容性

- 原工作台座標預設保留，尤其使用者最新貼上的旅行長褲：男性腰(-1,-6)、左褲管(-1,-8)、右褲管(0,-8)；女性三層(0,-6)。其餘白衣、披風、髮型、側包的原有數值不變。
- 本機 `transforms[key]` 在既有 `x,y,scale` 旁新增 `z`；沿用 `dungeon_dev_studio_v1_settings`，不更動正式遊戲存檔。
- 原本沒有 z 的本機設定／舊版 JSON 匯入時自動為每層補上 Z 預設值；保留其 x/y/scale。
- 匯出 `dungeon-character-asset-library-v1` 的每個 layer 現在會包含 `z`，重新匯入能還原該層 Z，舊 JSON 相容。
- 「重設此圖層」「恢復已確認服裝位置」「重設全部位置與顯示」會同時恢復各層初始 Z 和已確認的 x/y/scale，絕不把已核准的長褲位置變回 0,0。
- 上傳透明 PNG 的像素、男女角色底模、披風／背包原圖均未被重畫或移除。
