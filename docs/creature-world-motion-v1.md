# 燈火核心：八方向世界移動與景深 V1.0 / 苔棘鬃獸 V3.6
- creature_world_motion_v1.js：create(config) / vector(direction) / position(x,z) / advance(pos,direction,mode,dt) / project(pos)。X 向右、Z 向鏡頭，方向0面向鏡頭、2右、4遠離、6左。斜向速度為單位向量，避免加速。每秒世界單位：行走14、小跑38、疾跑85，初步測試值，可個別設定。
- 世界範圍 X ±100、Z ±90。停止於邊界，不瞬間傳送。畫面遠近比例78%～112%，基於世界落點而非動畫高度；本體和陰影共用投影，影子固定地面。
- 獨立 V3.6 頁：預設場景移動；可切原地步態、停止、回到中央、顯示景深線。沿用 V3.5 轉向時鐘與方向骨架；移動中轉向採近似角度路徑。
- 世界移動暫限行走、小跑、疾跑。攻擊、跳躍在場景模式原地播放，原地模式保留舊側向位移預覽。尚無障礙碰撞、世界足點鎖定、戰鬥追擊 AI、多生物排序及完整景深遮擋。實際動畫須手機驗收，未修改正式遊戲與原骨架。
- 48000 次世界位移取樣、180 組景深間距、9 個視窗邊界位置檢查。新增可重跑 Node 測試 tests/creature-world-motion.cjs。
