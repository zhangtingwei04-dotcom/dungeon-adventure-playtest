# 表情動態系統 V2（主角與未來 NPC 共用）

## 已完成

- 2026-11-21：正式遊戲裝備欄、男性獨立表情試演頁和共用控制器已更新。
- 控制器 `assets/expression_motion.js` 提供每角色獨立的 `createActor`、`setStatus`、`setExpressionOverride`、`setBlink`、`sample`。
- HP 四種循環：76–100% 健康＝睜眼微笑＋自然眨眼；51–75% 普通＝中性＋慢眨眼；26–50% 虛弱＝中性＋汗珠移動＋更慢眨眼；0–25% 瀕危＝眼內 3×3 像素圈圈持續四幀旋轉＋汗珠交替移動，不正常眨眼。
- 小圈圈眼旋轉和汗滴動態是狀態本身的動畫；不是隨機播放一次，也不依賴手動表情按鈕。
- `index.html` 的「預覽四種狀況（不修改 HP）」可以直接驗收；`male-expression-preview.html` 更提供四個獨立狀態切換按鈕。
- 保留原 64×160 透明圖層、髮型、眼睛、衣服、背包與存檔資料。異常狀態額外疊圖，不覆蓋五官來源。
- 動畫由已存在的可見畫面循環取樣，沒有替每個 NPC 新開計時器；隱藏分頁不更新。
- 已通過三份 JavaScript 語法檢查，並以控制器測試驗證健康微笑睜眼、瀕危圈圈眼 0→1→2→3 連續循環、瀕危不眨眼、虛弱汗滴循環、NPC 狀態獨立。

## 未來 NPC 接入

- 每名 NPC 擁有自己的控制器實例與時間起點；表情動畫邏輯共用。
- NPC 的眉／眼／口素材和眼睛旋轉中心必須使用 NPC **自己的**美術座標。不得直接把男性主角臉貼在其他角色身上。
- 共用控制器提供 `drawSpiralEye(ctx,cx,cy,phase)`，可按 NPC 眼位繪製旋轉效果。
- 當 NPC 真正擁有分層立繪時才將其 actor 接進場景循環；目前主角的男性版已完成接入，其他角色只完成通用接口。
- 手機實際視覺效果仍待玩家檢查，特別是圈圈是否落在眼內及汗滴是否太密集；未驗收前不要動原始底模。

## 2026-11-21 微汗顯示調整（V2.1）

- 汗水不再是藍色大水滴，也不沿身體各部位撒滿水珠。
- 虛弱：臉側的一個微小半透明像素汗光，緩慢移動／明暗變化。
- 瀕危：額角與臉頰幾個獨立的細汗反光，輕微循環；眼內的圈圈眼仍持續旋轉。
- 中暑／缺水相關外觀預覽也使用臉部微汗特效，不再補畫大顆汗滴。
- 由共用 `DungeonExpressionMotion.drawFaceSweat(ctx,status,phase,layout)` 繪製；未來 NPC 可以依自身臉部位置傳入座標，無需複製主角外觀。
- 主角原像素底模、服飾、髮型、裝備與存檔保持不變；已驗證語法與汗光僅 1×1 像素，iPhone 實機觀感尚待驗收。
