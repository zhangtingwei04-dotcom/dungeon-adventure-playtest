# 燈火核心：生物素材與陰影規範 V1.0
適用：怪物、野生動物、NPC 與角色的新製動態素材。
- 生物母圖與每幀動態素材須使用透明背景，不包含地面投影。保留身體本身的明暗、材質、接觸部位輪廓。
- 既有核准原圖保留不覆寫。清理需逐素材確認，禁止對未審核的生物套用通用色彩移除。苔棘鬃獸四張母圖有獨立尺寸與清理區域。
- 陰影以世界地面座標繪製，與生物的高度、旋轉、骨架分離。水平跟隨，跳躍及飛行不改變地面 Y。
- 核心 assets/creature_shadow_v1.js 提供 calculate 與 draw；依體型指定 width/depth；height、light、weather 為輸入，光照與天氣係數需由各場景供應。
- 目前消費端為 moss-beast-rig-v2-preview.html，正面／斜側／側面／休息母圖與側面骨架已使用。正式場景、其他生物與舊動畫幀尚未遷移。清理有少量邊緣殘留的可能，須逐圖視覺驗收。
- 驗收：透明素材、腳爪完整、起跳與降落時影子固定於地面、轉身無雙重影子、實機效能測試。未驗收不得直接替換正式素材。
