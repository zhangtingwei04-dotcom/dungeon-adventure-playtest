## 生物
林間空地既有陌生林地生物採三個固定地面位置之一。第一次探索出現，其後探索暫定 25% 離場、45% 換位置、30% 留下；離場至少隔兩次探索才可再次判定，回歸機率暫定55%。原遭遇已解決則不重生。不是新增通用怪物池。舊存檔已探索但未解決的生物初始顯示於原位置。無現實時間驅動位移。生物不存在時舊聲響互動只提示繼續觀察。原戰鬥、迴避和存檔保留。
NPC 與生物使用 CSS 輕微呼吸縮放，草叢使用輕微擺動；無行走動畫。原 NPC 的60遊戲分鐘有效期不變。尊重減少動態效果系統偏好。

## 植被
開場、林道、空地、遺跡、近郊各六個預設位置，每次最多兩片暫用短草。首次到訪初始化起始遊戲日，同一日位置與狀態固定。四日週期示意：嫩芽、成長、成熟、部分枯萎，下個四日週期換另一組位置。三組輪替。此為測試用週期與座標，非最終生態模擬。裝飾性短草不攔截點擊，與原可採集草叢及材料佇列分開，防止重複資源。沒有改動背景插畫、馬車、稀有物種機率、既有裝備和原劇情。
