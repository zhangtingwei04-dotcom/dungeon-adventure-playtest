# 心象核心 V1.0（規則與資料原型）
2026-11-28。此版是最新心象法設計基準，取代舊12屬性／36職業及四職業能力分類；歷史文件保留。僅迷宮盡頭的燈火。
- 心象法修習者：御心者。燈火會正式成員：執燈者。
- 燈為共同根基；六相順序光熱餘影滅續；對相禁修，最多三個互不對立相。主相100、鄰相75、隔相40、對相0，純燈100。投入分流後各自換算，不相加為超過100%的效率。
- 七境：覺心、凝象、顯象、塑象、化、展界、明我（完整名稱見程式）。
- 三個純燈流派可以學合法單相基礎技能，不能專修十八衍象或多相組合；十八個六相流派可研修合法衍象及組合。每個流派三個傳承招式名稱暫存，尚無已核准效果或數值。
- 觀察一次，取得記錄即可供技能創建與改造；不消耗、不要求觀察等級。原始技能與改造來源保留。
- 基本功燃守斂流、進階功聚護隱附察衡湧；純燈100%指轉換效率上限而非無消耗。燈心、燈火、燈域、燈印、燈器、燈蝕、燈鏈及燈獸(影+續)、燈偶是技術分類／示例，不固定角色技能名。
- 外部遺物可獨立提供力量，例如影續燈獸搭配餘遺物；不代表角色兼修對相。遺物媒介驗證未實作。
## 使用
assets/mind_core_v1.js：DungeonMindCoreV1；提供資料、合法組合、轉換、角色修行檔、觀察記錄、技能驗證、創建及改造來源。現有 engine registry 已預留註冊接口，載入時自動註冊 mind.core。玩家與 NPC 可共用同一資料格式。
node tests/mind_core_v1.test.cjs
## 暫定實作界線
獨立原型每份修行檔只指定一個流派（未定多流派切換）；允許已修習的單相基礎技能，複合技能須含流派核心相；允許不需要觀察素材的純技術研發；觀察ID由遊戲調查事件日後提供，呼叫端必須驗證實際觀察與特徵。每種相目前只支援一個衍象欄位，待擴充。分配 share 為100點百分比預算；結果只是理論上限而不是傷害、熟練度或實際消耗。
尚未接正式頁、存檔遷移、技能效果執行、反噬、境界門檻、傳承授權、素材特徵／行為驗證、核心技能數量、正式UI或遺物；不可視為已上線。

- 八種候選效果模板：自身強化、外展衝擊、能量轉化、殘留印記、短暫形體、力量抑制、維持連結、燈獸形體。模板要求相別，發動時重新驗證角色持有技能與完整心象核心規則。
