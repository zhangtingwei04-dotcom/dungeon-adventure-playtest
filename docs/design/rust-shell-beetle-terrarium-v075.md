# 鏽殼甲蟲：商人委託與簡易生態箱（V0.7.5）

## 已確認的世界觀
- 地表人類是主要居民；「怪物」是人類對尚未充分理解的非人類生命的慣用稱呼，不表示生物必然邪惡。
- 在原本林邊舊馬車殘骸旁，將「拾鐵小妖」改為 **鏽殼甲蟲**。牠收集金屬碎片覆蓋背甲，通常對人類警戒，不主動攻擊。
- 月紋兔和其他林地遭遇仍保留。以原創生態行為先於戰鬥分類。

## 玩家路線（已實作）
1. 遊戲進入第二章城鎮街道後，開啟右側「地點 → 附近可互動」，選「向雜貨商詢問甲蟲委託」。
2. 接下委託，取得通風誘捕盒。前往林間小徑，使用探索或搜尋找到 **另一輛舊馬車殘骸**（不是開場事故馬車）。
3. 再開啟右側「地點 → 附近可互動」，選「設置甲蟲誘捕盒 · 10分鐘」，必定安全捕獲一隻（不需要等待 2% 野外稀有遭遇；稀有事件仍可隨機觸發）。
4. 返回城鎮街道向雜貨商回報觀察報告。商人不收走甲蟲，贈送小型生態箱。
5. 在「旅程日誌 → 生態箱」查看和照顧甲蟲；「旅程日誌 → 怪物圖鑑」查看已解鎖的觀察線索。

## 數值（已實作）
- **飽食度**：初始 72/100，每經過一個遊戲內日數 -12；餵食 +25（最多 100）。
- **清潔度**：初始 85/100，每個遊戲內日數 -8；清理 +30。
- **舒適度**：初始 68/100，每個遊戲內日數 -6；整理環境 +20。
- 每次照顧花 10 遊戲分鐘，不額外消耗遊戲貨幣（貨幣系統還未實作）。
- **實際離線時間不消耗數值**；只有遊戲時間跨日才更新。單次最多計算 7 個遊戲日，低數值不會使甲蟲死亡。
- 本版不增加溫度、濕度、繁殖、即時 AI、3D 動態或複雜生態環境編輯。

## 手動驗收清單（實機仍待核對）
- 舊存檔能開啟，固定畫面與原有事件不變。
- 城鎮街道右側「地點」能看到商人入口；接任務後，回林間舊殘骸能找到誘捕行動。
- 捕捉後回商人完成報告、領取生態箱；任務只能領一次，不複製甲蟲。
- 三項數值的 +25 / +30 / +20 操作和 100 上限正確；跨日衰減、離線不衰減。
- 日誌兩個新分頁與收合／捲動在實際 iPhone 橫式畫面沒有文字重疊。
