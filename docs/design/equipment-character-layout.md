# 《迷宮盡頭的燈火》｜右側人形剪影裝備欄設計

## 已確認的介面原則

- **最新已核准視覺方向**：不使用完整人物立繪，而是在中央放**小型、低對比的金色人形剪影**，配上向周圍裝備格延伸的纖細連接線，參考使用者提供的裝備介面圖片與其後核准的生成示意。
- **2026-11-20 最新介面調整：裝備格直接顯示在右側原有「裝備」分頁中，不再開啟獨立的彈出視窗。** 中央部位定位底板兩側保留獨立裝備格，玩家可清楚辨識各部位。
- 當裝備槽空著時，保留可見的空格與部位提示；有裝備時顯示裝備圖示。具體穿戴及卸下功能仍待實作。
- 裝備欄只使用無五官、無服裝細節的**淡金色人體輪廓**，不是完整角色立繪；既有角色肖像仍留在角色資訊與劇情，不受影響。

## 操作建議（未定案）

1. 點對應部位的空格，顯示該部位說明；未來有可穿戴背包物品時再接入真正的選裝操作。
2. 已穿戴裝備點擊後可以查看屬性、比較或卸下，且卸下時需安全處理背包容量。
3. **已改為右側裝備分頁原位顯示**，不再遮住中央探索場景；874×402 手機橫式版為優先檢查尺寸，右側欄位允許獨立上下捲動。
4. 剪影淡金色且低對比，不遮蓋文字、裝備格；線條不能溢出裝備面板；手機橫式按鈕必須可操作。
5. 未真正穿戴前，不顯示假的裝備數值或不存在的裝備名稱。

## 人形剪影微調（2026-11-20 已同意並實作）

- 保留裝備欄原本尺寸、右側固定位置、左右各五個裝備格、金色引導線與點擊互動。
- **頭部與頸部**：頭型由扁長橢圓改成更自然的下顎輪廓，短頸銜接肩膀；不添加五官。
- **肩胸、腰胯**：放寬肩部、柔和肩部斜率，讓胸腰與臀部收放更自然，不再是直筒人形。
- **雙手**：上臂自然下垂，肘部微彎，雙手落在腰臀旁，不再像外張的符號。
- **雙腿與腳**：加入膝部與腳踝的微小起伏，雙腳稍微分開站立，保持腳底落地感。
- **材質**：維持低對比淡金外框，但內部加入透明度很低的深綠色填色，以及少量人體線條，讓形狀較有厚度。
- **明確未修改**：任何裝備格、物品資訊、背包容量、戰鬥數值與存檔格式。
- 這是裝備欄中的概念剪影，非主角正式人物美術；後續若仍需改比例，僅調整 SVG 路徑即可。

## 初始裝備與內衣分層（2026-11-22 最新決定）

- **玩家開局就穿著整套旅行裝**：旅人上衣（上身）、旅行長褲（下裝）、皮革長靴（鞋子）、深綠金邊披風（外衣）、棕色皮革手套（手部），並配戴附魔旅行側包（背包）。這六件均是已持有且已裝備的正式初始物品，不是試穿品。
- 頭部、主武器、副手及飾品在開局時維持空格。披風裝飾、腰帶扣與側包紫色魔晶屬各自裝備本身的視覺細節，不另憑空加入裝備格。
- **米白背心、深灰短褲是角色內衣圖層，不算裝備**；不占裝備格、不進入已持有裝備清單。脫下外穿上衣或褲子時，原本內衣仍會顯示。
- `STARTER_OUTFIT_V2` 為六件開局裝備的單一資料定義；`createStartingEquipmentV1()` 同時建立穿戴欄位、擁有清單及一次性版本標記。
- 對舊存檔做一次性的安全補發：先前只有側包的存檔獲得已穿上的旅行套裝；若既有存檔曾自行處理其他裝備的穿脫，不覆蓋既有選擇。側包若被手動卸下，也不強制穿回。
- 現有旅行裝圖集可顯示外衣、上衣、長褲及靴子等主體；**手套的裝備欄資料、存檔及穿脫已接入，獨立手套像素圖層及專用圖示仍待製作與驗收**，不使用其他裝備圖片冒充。
- 圖下方四種替換包款屬擴充方向，不是玩家同時獲得的起始背包。側包設定維持 24 格、16 kg 上限、減重 50%，實際負重規則仍未開放。


## 穿戴與卸下操作第一階段（2026-11-22）

- 目前六件開局裝備（上衣、長褲、長靴、披風、手套、附魔側包），在右側「裝備」分頁可以點擊部位，立即在紙娃娃圖下方按「脫下／裝上」；右側「背包」分頁的「已持有裝備」亦可逐件穿脫。
- 穿戴狀態記錄在原本 `equipmentV1[slotId]` 中，脫下設成 `null`；物品仍保留於 `equipmentV1.owned`，無複製、丟棄、移除背包物品，並沿用既有 `save()`。
- 已脫下而仍持有的裝備在格中提示「已脫下 · 可重新裝上」，點格選取即可找到操作鈕。
- 原有旅行裝與附魔側包圖片已被使用者認定不合適，暫在正式裝備格及紙娃娃停用。新的像素圖完成前，紙娃娃持續顯示原始內衣底層；**穿脫已能操作並存檔，但衣物美術尚未呈現**。不使用舊圖誤當新圖。
- 男女頭部、內衣底圖、角色自訂、持有物品、存檔格式與開局裝備內容保持不變。
