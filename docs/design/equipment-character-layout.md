# 《迷宮盡頭的燈火》｜角色人形裝備介面設計

> 2026-11-20：已在 `index.html` 實作角色置中裝備面板原型。穿戴、卸下與取得新裝備仍未開放。

## 已確認的介面原則

- 裝備欄不只是一排文字清單，應有一個**人物形象作為中心**。
- 人物對應的身體位置旁，顯示**獨立裝備格**，讓玩家清楚知道頭部、身體、手部、腳部等裝備穿戴在何處。
- 當裝備槽空著時，保留可見的空格與部位提示；有裝備時顯示裝備圖示。具體穿戴及卸下功能仍待實作。
- 人物應使用本遊戲主角的**既有角色設計**（銀灰髮、紫眼、深綠斗篷等），不能用隨機不相干的角色取代。現有素材是主角肖像；如要呈現全身像，需另行製作與肖像一致的原創全身版本。

## 建議配置（槽位數量、細節尚未確認）

以角色全身像置中，空格分列兩側，視覺上對準裝備部位，而非單純平均排列：

| 位置 | 左側候選 | 右側候選 |
| --- | --- | --- |
| 頭肩附近 | 頭部 | 飾品（護符、項鍊等） |
| 上身附近 | 上衣／護甲 | 外衣／披風 |
| 手部附近 | 主武器 | 副手／護具 |
| 腰部附近 | 腰帶或其他小件 | **背包／附魔旅行側包** |
| 下身附近 | 下裝 | 鞋子 |

- 以上是**布局候選**，不代表已定案全部十個裝備槽。原型目前只有「武器、防具、飾品」三項文字欄位。
- 初始附魔單肩側包設計已確認：**24 格、內容物上限 16 kg、減重 50%**；將來可在對應的背包槽裝備、更換，但實際負重驗證尚未開放。
- 錢袋繼續獨立管理，未確認是否需要單獨裝備槽。
- 主角已融合的特殊遺物不自動放進普通飾品格。

## 操作建議（未定案）

1. 點人物周圍的空格，顯示該部位可穿戴的背包物品；沒物品時顯示清楚的空狀態。
2. 已穿戴裝備點擊後可以查看屬性、比較或卸下，且卸下時需安全處理背包容量。
3. 在 874×402 一類的手機橫式畫面，最好由右側「裝備」頁籤開啟**可關閉的完整裝備面板**，而非硬塞進狹窄的右側欄位；保留既有地點、旅途紀錄及遊戲動線。
4. 人物比例與格位不要拉伸；裝備頁可內部捲動，避免手機上的按鈕過小。
5. 未真正穿戴前，不顯示假的裝備數值或不存在的裝備名稱。

## 第一版已實作的畫面（2026-11-20）

- 點右側「裝備」分頁，打開獨立的人物裝備面板；仍能在右側分頁點「開啟角色裝備圖」再打開。
- 中央為**原創全身裝備示意人物**：銀灰髮、紫眼、深綠斗篷、舊旅裝及腰側包，僅作裝備畫面的視覺替身。此版本是簡化 SVG 示意人物，**不是之前核准的半身肖像，也不是最終人物美術**。
- 左右共十個可點選的裝備位置：頭部、上身、主武器、下裝、鞋子、飾品、外衣、副手、手部、背包。
- 各格可點擊，顯示部位說明和已裝備／未裝備狀態；初始背包槽顯示已裝備的「附魔旅行側包」（24 格／16 kg／減重 50%）。其他格維持空狀態，不憑空產生物品或數值。
- 有關閉、Esc 關閉、點暗色背景關閉，以及「查看背包」返回現有背包系統；裝備面板的手機橫向 CSS 專門處理 874×402 等尺寸。
- 新存檔增加 `equipmentV1` 起始側包資料；舊存檔缺少欄位時將安全補入。當前尚無真正裝備物品名單，空槽不開放虛假的穿戴或卸下操作。
- 沒有修改既有戰鬥能力、物品取得、日誌、地點、商店或回收分解流程。
