## 已確認的介面原則

- **2026-11-20 最新決定：不顯示人物**；中央改成縮小的淡色裝備定位底板，只保留頭、身、手、腿、足等簡單部位標記。
- 中央部位定位底板兩側保留**獨立裝備格**，玩家可清楚辨識頭部、上身、武器、手、腳、背包等位置。
- 當裝備槽空著時，保留可見的空格與部位提示；有裝備時顯示裝備圖示。具體穿戴及卸下功能仍待實作。
- 裝備面板**不需要人物立繪或人物剪影**；原有主角肖像仍維持在角色資訊及劇情用途，不受此次介面調整影響。

## 建議配置（槽位數量、細節尚未確認）

以簡化裝備定位底板置中，裝備格分列兩側，清楚區別裝備部位。中央底板佔框內約 60%～70%，不呈現人物：

| 位置 | 左側候選 | 右側候選 |
| --- | --- | --- |
| 頭肩附近 | 頭部 | 飾品（護符、項鍊等） |
| 上身附近 | 上衣／護甲 | 外衣／披風 |
| 手部附近 | 主武器 | 副手／護具 |
| 腰部附近 | 腰帶或其他小件 | **背包／附魔旅行側包** |
| 下身附近 | 下裝 | 鞋子 |

- 以上是**布局候選**，不代表已定案全部十個裝備槽。原型目前只有「武器、防具、飾品」三項文字欄位。
- 初始附魔單肩側包設計已確認：**24 格、內容物上限 16 kg、減重 50%**；將來可在對應的背包槽裝備、更換，但實際負重驗證尚未開放。
- 錢袋繼續獨立管理，未確認是否需要單獨裝備槽。
- 主角已融合的特殊遺物不自動放進普通飾品格。
