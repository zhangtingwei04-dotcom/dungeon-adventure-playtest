# 《迷宮盡頭的燈火》｜隨身錢袋與旅行背包 V1

> 2026-11-20：第一版已開始實作。完整經濟、交易、負重仍未開放。

## 已接入主程式的第一版

- **隨身錢袋**：與背包物品分開儲存，存檔欄位 `wallet: {silver, copper}`。
- **暫定起始資金**：1 銀幣、12 銅幣。此前只是建議值，**尚未確定正式世界幣值及物價**，不可據此推導銀銅兌換比例。
- 讀取舊存檔時，若沒有錢袋欄位，會自動建立與新遊戲相同的暫定初始金額；保留其他存檔欄位。
- 背包在既有右側「背包」頁顯示，錢袋排列在背包上方；金錢不佔背包空間。
- 背包分類：**全部、物品、材料、特殊**；顯示種類數、數量與堆疊數。
- **不建立第二份物品清單**：背包畫面直接整理已有的 `recovery.items`、`items`、`recovery.parts`、`forestRare.ingredients`、`forestEcology.ingredients` 與甲蟲相關任務物品，不轉移或刪除舊資料。
- 「鑑定／分解與完整紀錄」仍開啟原有的物品紀錄頁，既有探索流程不變。

## 初始背包與後續升級（2026-11-20 更新決定）

- **初始背包型態已改定：較大但不顯笨重的單肩斜背側包**，以深綠／棕色布革混合材質配合主角旅行服飾；不再是雙肩背囊。正式名稱尚待決定（暫以「附魔旅行側包」作設計稱呼）。
- **側包本身確實具有收納附魔**：外觀是實用的單肩旅行側包，內部可用空間因附魔而比同尺寸普通包更大，能收納更多物品。這是確定設定，**不是「可能有魔法」的未解謎團**。
- 先前討論的「輕旅背囊｜12 格｜12 kg」屬舊版設計，**已由附魔單肩側包取代**；新背包的格數、重量上限、堆疊上限及附魔原理的具體數值 **尚未定案**。程式目前也沒有啟用容量／重量限制。
- 外觀與用途：單條斜背肩帶、較寬的主袋及翻蓋，可放置在身側，適合長途旅行與探索。包體可以比先前輕旅背囊更寬，但**不應為了大容量而畫成大型行李袋**，容量優勢來自內部附魔。
- **錢袋獨立存放**，錢幣不占背包格數；與現有的錢袋功能一致。
- **後續可以在商店購買其他背包**，以容量、材質、用途與重量特性提供多種選擇；玩家可以一直沿用初始附魔側包。
- **可以取得具收納功能的魔法道具**，也可以找到**具有相同或更特殊儲物能力的遺物**。它們不一定只是增加普通背包格子，可依其能力發展獨立收納機制。
- 魔法道具與遺物的取得方式、限制及負面效果應符合世界觀；尚未確認具體價格、倍率、魔力消耗、特殊空間規則或可否存放活物。

### 後續擴充候選（僅提案，非定案數值）

| 分類 | 可能定位 |
| --- | --- |
| 一般商店背包 | 透過普通交易改善容量與負重，沒有魔法效果 |
| 特製旅行背包 | 更好的收納結構、不同用途 |
| 魔法收納道具 | 在符合施法或道具條件時，提供額外空間或減輕部分負擔 |
| 儲物遺物 | 具有獨特來歷和使用方式的特殊收納能力，可能需要研究或特殊傳承 |

### 實作順序與存檔保護

1. 保留目前錢袋與背包的可用介面，將初始包型改定為附魔單肩側包；**新格數／重量上限暫不寫死**。
2. 待普通背包與附魔背包的容量、重量及堆疊規則有可靠定義後，再實作新的容量計算與收納附魔效果。
3. 導入限制時不得自動刪除、消耗、丟棄或隱藏既有存檔中的物品；已超出的舊存檔需有安全的相容處理。
4. 初始側包的收納附魔屬已確認的開場裝備設定；獨立的魔法道具與遺物收納機制則待普通購買及物品系統成熟後逐步實作。

## 原則

- 主角是這個世界的人，失憶不代表沒有過去財產；尋找舊財產或身世不應是正常冒險的必備條件。
- 第一版以手機橫式可用、保護舊存檔、低成本持續開發為優先。
