## 不可覆蓋的決策
- **第二張參考圖是唯一的正式美術基準**。不自行新增不同的裝飾風格，不以其他生成圖替換。
- 採「固定美術圖層＋可互動元件」分離策略。金色外框、標題邊框、葉片、藤蔓、蘑菇、水晶及植物分隔線屬美術；標題文字、旅途紀錄、敘事、路線按鈕、地點與菜單保持動態。
- 參考圖的原始尺寸為 **1536 × 707**。以此尺寸記錄設計座標，再使用等比例/相對座標適配橫向手機與安全區。
- 不修改遊戲事件結果、存檔、探索時間、地點解鎖、路線轉換等邏輯來追求外觀。
- 先完成左側整體，接著才依序處理中央、右側、底部；每輪修改應檢查相鄰元件，不只挑一點調整。
- 禁止把整張參考畫面直接當單一不可互動背景來假裝達成；文字/按鈕不得成為烘焙在圖像上的死元素。
- 「完全一樣」的驗收：在指定視窗尺寸下盡可能像素對齊，但字型、渲染、動態紀錄與不同螢幕比例可以合理不同，不能宣稱已經百分之百達成而沒有實際視覺驗收。

## 固定設計舞台／比例縮放（2026-11-20，V0.7.0–0.7.1）
- 經核對，選定的原始概念圖為 **1536 × 707**，其整體比例約 **2.173:1**；「16:9」只適用於中央遊戲場景，而非整張 UI。「2.1:1」亦非完全吻合，因此不以該近似比例取代設計稿。
- 橫向手機與桌面：以 `#app` 為 1536×707 的固定設計舞台，使用 `min(可見寬/1536, 可見高/707)` 進行等比例縮放與置中，多出的空間以背景留白（letterbox）處理，不拉伸畫面。
- 直式手機：退出鎖定模式，保持原有旋轉手機提示；避免縮成難以閱讀的小舞台。
- 主畫面採固定舞台座標（標題、旅途紀錄、敘事、馬車畫框、右側地點卡與底部操作），而非以 CSS 流式排版重新推擠。所有原有 `id`、事件紀錄資料與 JS 互動都保留。
- `?layout=fluid` 為供對照與緊急回退的瀏覽器參數；不更動玩家存檔。
- 原圖中的參考文字或範例佔位符不能直接取代實際玩家紀錄；旅途紀錄仍以真實遊戲事件動態產生，收合／展開仍可用。
- 右上四鍵保持主框內留邊，底部操作與水晶留間距；面板與選項在縮放後使用較大文字和觸控高度維持可用性。
- 靜態驗證通過：JS 語法、元素 ID 單一性、SVG 成對、存檔/主按鈕/地點欄程序存在。**尚未實際取得新版 iPhone Safari 的渲染截圖**，不得宣稱不同平台完全不跑版或 100% 像素一致。
- 下一次驗收：iPhone Safari 橫式、桌面 16:9、原生接近 1536×707 的視窗、直式旋轉提示；特別測試地點卡展開、各種旅途紀錄長度、按鈕可點擊區，以及瀏覽器頂部工具列隱藏／顯示後的舞台重新置中。
