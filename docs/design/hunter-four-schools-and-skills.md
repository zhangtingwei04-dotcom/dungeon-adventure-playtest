# 《迷宮盡頭的燈火》｜獵魔師四大戰鬥職業與師承系統

> 設計紀錄：2026-11-20（台灣時間）
> 狀態：**名稱與核心架構已確認；技能詳細數值、師傅角色及解鎖條件尚未實作／尚待規劃。**
> 本文件只保存使用者已確認的方向，不代表目前遊戲功能已完成。

## 1. 職業總稱

- 戰鬥職業體系總稱：**獵魔師**。
- 四大方向各有自己的**三字專屬職業名稱**，正式稱號後面**不加「獵魔師」**。
- 四個名字最後一字不同，彼此要有辨識度。
- 獵魔師不是整個世界所有旅人或探索者的統稱；平民、商人、其他探險者仍可存在。

## 2. 四大方向（名稱已定案）

| 戰鬥方向 | 正式職業名稱 | 對應師承流派 | 主要特色 |
| --- | --- | --- | --- |
| 近戰、格擋、反擊 | **斷鋒衛** | 斷鋒流 | 近戰攻防、反擊、瓦解敵人攻勢 |
| 追蹤、速度、精準 | **獵痕影** | 逐影流 | 偵察追蹤、洞察弱點、潛行與精準攻擊 |
| 魔力、符文、術式 | **術環師** | 星紋流 | 魔法陣、術式構築、魔力運行與組合 |
| 防護、治療、支援 | **守燈人** | 長明流 | 保護同伴、防護救援、恢復與持續支援 |

名稱更動歷程（僅供避免日後誤用舊稱）：
- 追蹤系由「夜巡俠」→「獵痕使」→最終 **「獵痕影」**。
- 術式系由「織律師」→最終 **「術環師」**。
- 守護系由「守燈使」→最終 **「守燈人」**。
- 近戰系維持 **「斷鋒衛」**。

## 3. 專屬技能與公共技能（規則已確認）

- 四個戰鬥方向各自擁有**專屬技能**，藉此展現不同戰鬥方式與師承特質。
- **其他一般技能為公共技能**，跨職業可學習；不應單純因為主職業不同而禁止學習。
- 生活技能（例如採集、製作、醫療、研究等）不受四大戰鬥方向的職業名稱限制。
- 主角因神秘遺物而具有的力量應為**獨立成長系統**，不是四大流派之一，也不應取代職業專屬技能。
- 各技能的實際內容、消耗、平衡、熟練度及解鎖方式尚未定案；此前舉出的絕技名稱都屬設計提案。

## 4. 師承方向

- 四個職業方向有相對應的**流派與傳承**。
- 可以透過師傅、學習及相關劇情，逐步接觸流派專屬技能；不同師承有發展個人故事及傳承任務的空間。
- 「拜師流程、是否轉職、是否可同時兼修、專屬技能限制」尚屬待詳細規劃的設計議題，**不得在未討論前當成既定限制**。
- **獵痕影**特別強調立場中立，職業身分本身不代表正義、邪惡或特定陣營。
