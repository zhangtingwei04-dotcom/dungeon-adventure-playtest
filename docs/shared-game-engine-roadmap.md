# 共用遊戲引擎架構與研發路線
確認日期：2026-11-25（使用者要求先記錄，尚未授權全面重構）
專案：迷宮盡頭的燈火。不得與鱗片與種子／歐姆計劃混用。

## 原則
單一資料來源、共用規則、資料驅動、模組化、獨立角色狀態；保留已驗收介面與既有玩法、舊存檔相容。逐一遷移而非一次重寫。預覽與正式遊戲狀態分離。新增地點、角色、生物、裝備、天氣應沿用既有核心與註冊資料，避免重複判斷與更新遺漏。

## 核心分層
- 基礎：模組註冊中心、遊戲時間、事件、存檔與版本遷移、資料註冊。
- 世界：環境（氣溫、風、降雨、積雪、積水、結冰）、生物習性（需求、覓食、休息、活動時段、避難）、場景地形（碰撞、高低、遮蔽物、行動點）、地點（資訊、縮圖、路線、交通）。
- 角色：玩家與NPC、角色生理（HP/SP、飢餓、睡眠、體溫、異常狀態）、角色環境、外觀（紙娃娃、圖層、表情、動畫）、NPC個性與關係、生活行程。
- 物品：道具、材料、裝備屬性、穿戴、耐久、重量、背包容量。
- 冒險：探索、採集、調查、道路發現、稀有遭遇、戰鬥、職業、技能、魔法、經濟與世界事件。
- 共用呈現：遊戲介面、場景渲染、動畫、音效、音樂。

## 開發順序（待後續執行）
1. 模組註冊中心與時間核心優先，接著事件、存檔。時間核心統一旅行、探索、休息及跨日等時間推進；系統註冊後隨遊戲時間更新，避免遺漏或重複計算。
2. 角色整合：生理、環境、裝備、紙娃娃及表情。
3. 世界整合：場景、地形、天氣、生物習性。
4. 冒險整合：探索、物品、NPC、戰鬥。
5. 進階：職業、技能、魔法、經濟、世界事件。

## 更新驗收
模組版本與相依性檢查、自動回歸測試、舊存檔遷移、開發診斷面板、開發記憶庫。新增功能時更新相依關係、測試及規範；iPhone 橫式實際驗收另行確認，不以語法檢查代替。
