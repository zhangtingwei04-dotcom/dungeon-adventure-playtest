# 男性 V3 眉毛與眼線誤分層修復｜2026-11-22

## 觸發問題
使用者錄影（2026-11-22 10:28，iPhone 的 17.7 秒螢幕錄影）在原始五圖層互動驗收頁，關掉「眼睛」後仍看到類似**半隻眼睛**的黑色線條，詢問「眉毛不是遮在頭髮下面嗎」。

## 真正原因
原始 V3 archive 的 `eyebrows_64x160.png` 實際畫的是**上眼瞼、眼線與睫毛**，非額頭上方的眉毛，覆蓋範圍約 (20,32)..(43,35)；眼睛圖層 `eyes_64x160.png` 在 (22,33)..(43,38)。因此原兩層高度交疊，切掉眼睛只剩上眼線，看起來是「半隻眼」。

## 已實作
- 保留已驗收原圖源 `assets/male_approved_v3_layers.js` 完全不變，僅新建修正版本 `assets/male_v3_corrected_layers_v2.js`。
- 原來誤稱 `eyebrows` 的黑色上眼線與原本紫色虹膜圖層**依照原疊圖順序像素合成為一張完整『眼睛＋睫毛』透明圖**；原眼睛像素沒有重新生成。
- 額外畫真正獨立的短弧形眉毛，左右對稱，位於頭部原生 **y29..30**、x22..27、x36..41。此眉毛與眼線圖層在原生像素上**完全零重疊**；髮型是最後上層，因此眉毛自然藏在銀白瀏海下面。光頭則能看見獨立眉毛。
- `index.html` 預設 V3 使用這份修正後的眉毛／眼睛；背景頭、嘴巴、頭髮仍使用先前完全相同的資料；修正模組先於 `male_approved_v3_adapter.js?v=3` 載入。
- `assets/male_approved_v3_adapter.js` 使用修正後原生眉毛 PNG 作為表情動畫來源；眉毛改動時擴大動態替換片範圍到 y27..41，避免原圖眉毛與新位置重影。
- 新增可用 iPhone 一一開關圖層的修正版測試頁 `male-head-v3-corrected-layer-preview.html`，畫面說明「真正眉毛（額頭）」、「眼睛＋原眼線」。舊版 `male-head-v3-approved-archive.html` 照舊封存（因此舊頁仍有原問題），方便追蹤先前誤標成因。
