# 女性試裝表情系統 V1（2026-11-22）

## 範圍

使用者接續《迷宮盡頭的燈火》開發者工具台 V1，希望把女性表情系統裝進目前的測試工作流。已建立獨立的女性試裝表情模組 assets/female_trial_expression_v1.js，並接入 developer-workbench.html。**尚未覆蓋正式 index.html 的女性頭部素材或正式表情行為**，先在工具台驗收。

女性頭部試驗版本：assets/female_bald_candidate_v1.js；原女性頭部與銀白髮：assets/female_parts_v2.js。工具台女性髮片仍預設 x=-2、y=-5。男性 V3 正式 V2 圓頂與既有表情程式不更改。

## 設計原則

1. **原圖中性 0 像素變化**：目前選擇的女性頭部 PNG 直接繪出；中性表情不畫任何表情補丁，完整保留先前確認的紫金眼神、皮膚色與頭部輪廓。
2. 動態表情是額外繪圖層，不能重做或覆蓋永久母版。每幀先從當前選擇的女性來源（試裝版或原正式版）重新取樣；不把舊女性 atlas／男性 V3 的臉膚色貼過來。
3. 試驗局部五官座標：眼睛 x22..28 與 x35..41、y35..40；眉毛擴充極小，口部 x30..34、y44..46。臉外輪廓、頭皮、耳朵、脖子完全不動。女性仍需進一步美術驗收後才能把眼嘴做成正式永久拆層。
4. 男女性別共同讀取既有 DungeonExpressionMotion 的 HP 四階段、眨眼排程、弱／戰敗汗滴與圈圈眼；女版使用獨立的 feminine patch 顏色／輪廓；不直接複製男性眼睛或嘴巴圖像。
5. 工具台增加雙性表情／HP、睡眠、異常狀態（八類）、說話口型試播；動態效果借用既有 renderer，皆是**視覺預覽**而非已接入遊戲實際疾病／疲勞機制。
6. 可在工作台開啟／停止動畫、手動走汗滴幀、前後比對、匯出帶表情的合成 PNG；不修改原始頭部、頭髮與存檔。

## 已驗證與待確認

- 女性模組已通過 JavaScript 語法檢查及像素模擬：中性繪製 0 額外像素；開心／驚訝／害羞／閉眼／虛弱的改動侷限在表情預定區域，原始來源 RGBA 未被修改。
- 工具台已核對相關 HTML 控制項與 JavaScript 綁定、程式解析成功，正式 index.html 未被這次表情系統修改。
- **未通過使用者 iPhone Safari 上的實際視覺驗收**。特別要驗證頭髮是否遮蓋新表情、眨眼能否自然、昏迷與夢境標記是否壓住髮束，以及口型是否保留角色原本神韻。
- 若女性表情有問題，退回工具台女性原始版／中性模式即可，不得重畫、覆蓋光頭和銀白髮母版。

## 正式遊戲更新（2026-11-22）

此文件原為試驗階段紀錄。女性新版 64×160 頭部後續已經使用者指定為正式唯一版本，`assets/female_bald_candidate_v1.js` 以 `DUNGEON_FEMALE_OFFICIAL_HEAD_V2` 對外提供正式素材；`index.html` 不再載入 `female_head_v1.js`，也不再透過試驗表情模組是否就緒決定是否回退到舊女性頭部。表情模組可選擇載入，但不影響基本新頭顯示。男性已核准頭部、男女共用內衣及裝備、存檔不受此更動影響。仍需 iPhone Safari 畫面驗證。
