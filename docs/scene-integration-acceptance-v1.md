# 燈火核心系統｜正式場景整合驗收準備（2026-11-27）
## 版本界線
- 苔棘鬃獸功能基準：V3.41（ebb47ea27fcd023ca2a55bb90f232ae8009ffa83）。凍結新動作、新 AI、新需求、新戰鬥能力及物種素材擴充；只允許整合阻斷、回歸、效能或視覺缺陷修復，修復須記錄。
- 共用渲染放入 assets/render_resources_v1.js：frameCache、sharedFrames；舊 onceLoad/imageCache 保留。正式 index 登記 engine.render-resources 與 engine.render-shared-frames，預設不啟用共享畫格於正式場景。獨立效能測試頁改用同一核心。
- 場景擁有快取實例；上限64張，每張最多35840像素（64張 RGBA 像素資料約8.75 MiB，不含瀏覽器額外開銷）。離場、換素材版本、重建畫布或品質設定改變時由場景清除。鍵須包括物種、素材版本、姿勢、實際動畫相位與外觀差異；不可用近似鍵替代不同姿勢。地形 IK、混合過渡、個體變形、特殊狀態與未驗證邊界預設直接繪製。景深、陰影、位置、天氣、事件、個體 AI 不共享。
## 驗收順序（均未完成實機驗收）
1. 獨立效能頁：1/5/10/20隻逐隻與共享比較；同一姿勢與畫格邊界，檢查裁切、鏡像、跳躍、陰影、視覺等價；記錄平均/P95提交時間、rAF、命中率。固定224×160邊界仍未驗證；比較頁不代表完整正式場景。
2. 正式場景獨立候選整合：以破損馬車為首個候選，保留既有探索、互動物件、兔子／甲蟲／鳥、天氣及戰鬥入口。單隻苔棘鬃獸、現有動態、地形落點、景深遮擋、採集刺激從物件實際座標傳入；不加入玩家場景模型，不把隱形測試目標當正式玩家，不新增傷害機制。
3. 比較候選場景直接渲染與共享渲染；只對可證明等價的局部姿勢啟用快取；不共享碰撞、腳掌鎖定、事件及個體邏輯。對話、採集耗時、探索刷新、移動出路、存檔不退化。
4. iPhone Safari 橫式：晴雨、雪、夜晚、切換地點、前後景、暫停恢復；記錄測試裝置、版本、FPS、P95、錯誤與視覺截圖。目標穩定30 FPS以上，60 FPS為理想，必須實測而非承諾。若快取無明顯收益或有裁切/記憶體問題則保留直接渲染。
5. 驗收通過後才以獨立開關接入正式場景；不替換正式遊戲既有戰鬥素材與規則直至回歸通過。
