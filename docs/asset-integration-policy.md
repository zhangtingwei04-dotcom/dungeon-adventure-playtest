# 遊戲素材製作與實裝規則

適用：《迷宮盡頭的燈火》。

- 每次完成符合已確認規格的正式素材，同一開發流程即進行素材整理、命名、必要的透明背景處理與遊戲接入，不只交付對話預覽圖。
- 正式素材應存放於對應 assets 子目錄，接到共用素材、場景或怪物資料定義；保持原有功能及存檔相容。
- 戰鬥背景使用固定構圖的無固定日月光源底圖、可獨立控制的馬車／殘骸物件層及共用時間與天氣核心。不可將有固定馬車、月亮或天候的整張概念圖直接當作通用底圖。
- 概念圖、規格圖集、失敗生成品與不符合要求的素材不可覆蓋已驗收的遊戲素材。
- 提交後確認主分支檔案、素材路徑及程式語法；未做實機驗證或上傳失敗時必須如實標示，不宣稱完成。
- 2026-11-26：使用者要求往後每次生成完成都放入遊戲。
