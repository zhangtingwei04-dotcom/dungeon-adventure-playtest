# V3.30 共用物件互動感知資料庫 V1.0
單一資料來源 assets/object_stimulus_catalog_v1.js；物件 ID、名稱、類別、聲響強度(0–1)、聲響持續(ms)、氣味強度(0–1)、氣味殘留(ms)。既有六項保持原值。新增物件使用 registry.register({...}) 或初始資料列，測試頁自動列出；自訂 catalog 可注入感知實例。註冊驗證重複 ID、範圍與必填欄位；實例事件仍帶 objectId、世界位置及可選強度覆寫。物件名稱僅測試顯示；不含正式物件採集、掉落、物品欄、玩家角色。124項資料一致性、舊新感知輸出比對、新物件與無效輸入測試通過；未實機驗收。未修改正式遊戲。
