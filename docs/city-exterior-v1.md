# 城鎮共用外景系統 V1.0

- 住宅後方窗戶：城鎮遠景，保留既有窗戶素材、雲、鳥、積雪與窗簾。
- 住宅右側門：街道近景，使用由確認的預覽裁切的獨立街景素材。門洞透視與動畫沿用。
- 出門：同一住宅區、同一街道 ID rental-street；目前街道全景仍是 SVG 草圖。
- 共用時鐘、天氣種子、光照與預覽狀態。窗戶玻璃的外景遮光與街道色調跟隨核心取樣，門口保留方向性光影。
- 後方、右側為相對方位，不代表已決定世界地圖的絕對東西南北。日出日落採固定時間曲線，季節、城市實際地圖、建築索引與街道天氣粒子尚未完成。
- 核心：assets/city_exterior_v1.js；新增住宅或門窗應註冊至共用視角資料，不另外抽取天氣。
