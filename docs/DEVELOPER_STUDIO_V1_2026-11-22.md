# 《迷宮盡頭的燈火》開發者總台 V1（2026-11-22）

正式入口：https://zhangtingwei04-dotcom.github.io/dungeon-adventure-playtest/developer-studio.html

本項為獨立的開發工具頁面，不取代正式遊戲，並可從 iPhone Safari 的「分享 → 加入主畫面」建立桌面捷徑。`dev-studio.webmanifest` 使用 `display: standalone` 與獨立的 `start_url`。主畫面捷徑功能仍依 iOS Safari 能力為準，不能保證裝置旋轉方向被自動鎖定。

## V1 已實作

1. **實際遊戲預覽**：內嵌正式 `index.html`，保留 1536×707 遊戲原生比例，並可另開完整頁面。預覽版帶 `?dev-preview=1`，遊戲 localStorage 使用 `dungeon_adventure_ch1_devpreview_v1`，正式存檔仍使用 `dungeon_adventure_ch1_v01`。重新開始與清除測試進度均不修改正式存檔。
2. **角色裝備庫**：讀取正式遊戲已確認的男女 body/tank/shorts 像素檔與目前的頭髮／頭部來源；支援男性與女性並排、獨立圖層前後疊加、X/Y 位置與 Scale、iPhone 觸控拖曳、一像素移動、顯示切換、重設與新增裝備／頭髮條目。
3. **匯入獨立透明 PNG**：依素材 ID × 性別 × 前/後/側圖層匯入單張 PNG；圖片保存在**本機 IndexedDB**，工作台設定另存 localStorage。資料沒有自動上傳 GitHub。圖片在更換裝置或清理 Safari 網站資料後可能消失，因此必須自行備份 PNG。
4. **JSON 資料交換**：可複製單一素材／全部 JSON、下載 JSON 與匯入 JSON；數據描述每個性別、圖層的位置、縮放、顯示與圖片的檔名／尺寸，但**不含圖片本體**，使用者需另將 PNG 附給助理才可完整裝載。
5. **舊工具保留**：入口可回到頭部／表情工作台與前期披風比較頁，不刪除已有功能。主遊戲內的穿脫與存檔照舊。

## 美術驗收與使用限制

- 之前「深綠金邊披風」程式圖與展示圖並不相同；圖庫 V1 中的程式披風明確標示「不合格草稿」且**預設隱藏**，不會冒充正式圖。其他舊衣圖被使用者否決，仍未正式安裝。
- 工具台與正式遊戲是公開 GitHub Pages 路徑，`robots=noindex` **不是**存取權限機制；勿放私人憑證或尚未願意公開的敏感素材。裝置本機匯入的素材不會自動上傳到網站，但連結與內建素材本身公開可見。
- 工作台調整只改動預覽與本機設定；**不會直接在遊戲裡套用**，須由使用者提供數值及對應素材、確認後再提交正式版。
- 頁面程式、GitHub 檔案與內嵌腳本語法已作靜態驗證，仍待 iPhone Safari 的實際觸控、iframe 和「加入主畫面」驗收。

## 2026-11-22：正式底模外框量測與披風尺寸警告

從 `assets/cloak_workbench_bases_v1.js` 原始 64×160 RGBA PNG（alpha>100）的有效畫素量測：男性身體 `x=4..58, y=49..140`，包圍盒 **55×92px**；女性身體 `x=4..58, y=51..140`，**55×90px**。本次原圖 V2 披風前層 `x=3..59, y=53..118`，**57×66px**；後層 `x=2..60, y=53..135`，**59×83px**。

後層左右寬度已接近 64px 座標限制，直接將整件放大會截斷左右金邊。使用者回報「披風太小」應優先理解為**視覺輪廓、肩部厚度及前片垂落比例不足**，非單純整張 PNG 解析度不足。開發者總台新增實際身體尺寸與肩線/腳底外框的輔助線，不默默修改已生成素材或動用正式裝備。下一版若要更寬的下擺，應採更大透明外框並改造角色預覽／裝備圖層畫面裁切，或在 64px 內重繪服裝輪廓；使用者確認後才替換。

## 2026-11-23：披風試穿後短褲視覺縮小的回歸修正

使用者發現披風測試版短褲（內褲）視覺變窄。追查原因不是 PNG 尺寸改變，而是先前針對手部角度修正的前景蒙版：在 `y=70..101`、左右 `x=0..23` 與 `x=40..63` 的區域中，把原本角色身體 `body` 畫到披風前方，覆蓋了已顯示的 `shorts` 左右側（原短褲大約涵蓋 x17..47, y79..100），所以短褲看起來縮小。

- 正式 `index.html` 把**完全相同像素的 shorts 與 tank**疊回手部蒙版內，順序為 `body → tinted body（非原色時） → shorts → tank`，不改圖檔或縮放。
- `developer-studio.html` 與 `cloak-fitting-workbench.html` 的 Canvas 遮罩同樣從原始 `body/shorts/tank` 依序重疊，不再只畫裸體 body。
- 男女性別各自採本來的衣物 PNG，內褲原始尺寸、角色手臂角度、頭髮、配件及玩家存檔不變。
- 仍待 iPhone Safari 實際畫面確認披風與短褲的局部遮擋關係。

## 2026-11-23：採用使用者工作台 JSON 的披風 V2 定位

使用者提供 `dungeon-character-asset-library-v1` 全部資料，現階段只採用 `starter_cloak` 的位置，不動原已核准的頭髮或未有圖像的裝備：男性 `back=(x0,y0,scale1)`、`front=(x0,y-8,scale1)`；女性 `back=(x0,y0,scale1)`、`front=(x0,y-6,scale1)`。兩性前後層都仍為可見，披風裝備 ID 仍是 `starter_cloak`。

- 正式遊戲只在使用者明確試穿 `?cloak=art2` 且已裝備披風時生效；新增 V2 專用 class 分性別轉換，分別相當於完整 160px 高度的 -5%（男 -8 px）及 -3.75%（女 -6 px），並保留原有所有圖層的 9 CSS px 共用位移。
- `developer-studio.html` 在沒有同素材本機設定時，以此組值為預設，使用者已存在的 localStorage 定位值不會被蓋掉；其餘 `hair_original` 設定（男 0/0、女 -2/-5）、裝備圖片以及顯示狀態完全不變。
- `cloak-fitting-workbench.html` 的男女前層也採相同值，頁面的 X/Y 共用滑桿作為額外位移；後層則維持 0。
- 這是工作台位置資料的整合，不代表披風美術核准，也不會改一般遊戲預設顯示、衣物、身體、頭部、存檔或裝備穿脫功能。
