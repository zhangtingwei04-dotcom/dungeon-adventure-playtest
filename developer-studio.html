實際遊戲預覽

下方會載入目前 GitHub Pages 的正式遊戲程式，但使用獨立的開發測試存檔。此區是玩法預覽；裝備庫調整尚未寫入遊戲時，不會同步改動下方的遊戲角色。

建議 iPhone 橫向操作。內嵌預覽保留遊戲原本 1536×707 版面；如果畫面太小，按「全頁開啟測試遊戲」。正式遊戲存檔與預覽存檔分開。
此處使用正式男女身體／內衣／頭髮素材。新增 PNG 可單獨定位、調整大小，並在男女預覽中測試。披風 V2 使用剛生成的原圖拆成透明前後層，可分別調整男女位置和大小；正式採用前仍需驗收。調完後到「數據與備份」複製數據給我。

原始身體尺寸（64×160 座標）：男性 x4–58、y49–140，實際 55×92px；女性 x4–58、y51–140，實際 55×90px。披風前層 x3–59、y53–118（57×66px），後層 x2–60、y53–135（59×83px）。披風已接近畫布最大寬度；過度放大會裁到左右金邊，應優先調整肩披、前片及衣襬輪廓。

圖層調整

匯入獨立素材圖

請選擇透明 PNG。匯入到「目前素材 × 性別 × 圖層」，不同角色與前後層可用不同圖片。原始檔案會保留在裝置的工作台資料庫，參數 JSON 不包含圖片本體。

請先選擇素材。

參數複製與備份

所有數據都是以 64×160 紙娃娃座標記錄，每一件裝備的男性／女性、前／後層分開。複製貼給我即可依數據安裝；如有使用你自己匯入的 PNG，請另外附上對應圖片，因為 JSON 不包含圖像像素。
