# 殘車之後｜地下城冒險公開測試 V0.3.7

> 《殘車之後》是**測試暫名**。這是獨立的原創異世界 2D 第一人稱冒險遊戲，不是《鱗片與種子：地下生態物語》。目前均為可修改的原型內容。


## V0.3.7｜冒險者登場與分段對話演出

- **四人森林登場**：在 `trail` 點選沿路前進時，先顯示「林間傳來腳步聲」的提示，四名冒險者以延遲交錯的 CSS 佔位人物從道路深處出現，約 1 秒後進入原有相遇分支；若裝置設定減少動態效果，則跳過等待。
- **人物隨存檔出勤**：使用已存在的 `s.party` 四個成員 ID 生成各自不同服裝色調與身高；以對應 NPC 的稱呼突出正在發言者，**不是正式角色立繪**，也不是實際可走動的完整角色模型。
- **對話分段**：先選「求助／詢問／沉默」之一，接著顯示第一位成員的回答，點「聽聽他們的提議」才顯示另一位成員與回城提議，最後點「跟著他們回城」；保留原本選擇記錄與救援旗標，不新增強制戰鬥或任務。
- **避免互動衝突**：短暫登場期間禁止從場景熱點、下方行動按鈕或旅途快捷鍵觸發其他行動；切換場景、匯入、重新開始時清除臨時人物與延遲。沒有恢復左右滑動、上滑執行或 ↶ 返回捷徑。
- **旅途紀錄**：第一次登場追加一則「腳步聲」紀錄，重玩與舊存檔相容。沿用舊 `dungeon_adventure_ch1_v01` 存檔識別和原本角色出勤。
- 私人與公開版本已更新，JavaScript 靜態語法檢查通過；需要在 iPhone Safari 真機確認角色遮擋、對話時機、按鈕可用性與旋轉螢幕後的排版。

## V0.3.1｜第一張背景圖尺寸修正

- 使用者反映手機橫式「背景圖片大小不適合」。問題原因是第一個馬車場景把固定 Canvas 設計尺寸 960×540（16:9）當作顯示畫面的裁切比例，但手機橫式視窗（例如 844×390）更寬，導致取圖過窄、馬車放大及左右內容裁切過多。

## V0.2.8｜手機操作手感優化

- **手機橫向優先**：底部主要操作鍵向右對齊、提高觸控面積；防止誤觸選取文字與雙擊縮放。日誌仍是透明三則滾動，劇情／存檔規則不變。
- **滑動操作**：V0.2.8 曾在 2D 背景左右滑動時切換可用行動，但**已在 V0.2.9 停用並由背景平移取代**；上滑仍執行主要行動。**目前不是真正的 360° 轉視角**，因為各方向尚未有獨立場景美術。滑動不會跳過原有劇情判斷。
- **日誌手勢**：在旅途紀錄的標題列向上滑縮小、向下滑展開，不攔截日誌內容本身的滾動。
- **回上一地點**：底部 ↶ 只切回近期上個場景，**不倒轉已發生的劇情、任務、物品或選擇結果**，最多保存 12 個地點歷程，讀取舊存檔自動補空歷程。
- **防連點**：主要行動及場景跳轉使用 300ms 防重複觸發；既有中央「查看周遭」選項直接點選即可執行。
- **鍵盤**：1、2（底部主要操作）、對話選項 1～3，方向鍵左右觀看背景／上鍵執行，J 或 L 切換旅程日誌，M 看地圖，Esc 關閉視窗或在空閒時打開設定。Tab 保留瀏覽器原生焦點循環以利無障礙操作。
- **暫不導入**「任意長按 2 倍速」與「劇情／分支快照撤銷」：目前沒有逐字稿或過場速度需要加快；劇情撤銷會涉及任務、事件與存檔一致性，不能與回上個地點混為一談。
- 本次已完成 JavaScript 靜態語法檢查及公開／私人程式同步；真實 iPhone Safari 的手勢識別、按鈕遮擋與存檔相容性仍需操作測試。

- 左側「旅途紀錄」調整為半透明深色、緊湊的**彩色訊息串流**：依事件發生順序由上往下堆疊，最新訊息位於底部，接近底部時自動跟隨更新；手動往上捲動時不強制拉回底部。

- 顏色區分路線移動、探索發現、人物對話、戰鬥、生活休息；增加已開啟 NPC 對話的簡要紀錄。
- 可互動地點仍位於訊息串流下方，點擊即可走現有路線；左側視窗可收合，完整旅途紀錄仍在右上角日誌。
- 存檔鍵與主線、隊伍、探索、委託狀態維持不變。**本版完成原始碼／JS 語法與公開、私人版本同步核對，但仍待 iPhone Safari 真機畫面、捲動、觸控測試。**
