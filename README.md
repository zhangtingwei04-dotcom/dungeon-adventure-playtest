# 地下城冒險｜第一章公開測試版

> **開發中的原創 2D 第一人稱冒險遊戲原型**。名稱《殘車之後》僅為測試用暫名，非正式遊戲名稱。

**遊戲入口：** [前往 GitHub Pages 試玩](https://zhangtingwei04-dotcom.github.io/dungeon-adventure-playtest/)（須先在儲存庫 Settings → Pages 啟用）。

## 試玩內容

- 在被摧毀的貨運馬車醒來，探索森林與附近遺跡
- 有機會遇見未知生物及不明物品，調查不是強制進度
- 體驗救援事件、城鎮與旅店短篇劇情
- 內建暫時性的回合制戰鬥、旅程日誌與本機自動存檔

## 遊玩

在 GitHub Pages 開啟本專案（設定好 Pages 後），建議使用**手機橫向畫面**或電腦瀏覽器。

此原型是**單一 HTML**，沒有外部程式套件、伺服器、帳號與 AI API 依賴。
存檔只保存在當前瀏覽器的本機儲存空間，可透過遊戲選單匯出備份；更換瀏覽器可能無法保留進度。

## 開發狀態

- 版本：V0.1，**非正式完成版**。

- 未完成：正式美術、聲音、手機 Safari 真機完整測試、可重現的完整冒險流程與雲端存檔。
