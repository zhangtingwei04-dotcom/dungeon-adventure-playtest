# 殘車之後｜地下城冒險公開測試 V0.2.7

> 《殘車之後》是**測試暫名**。這是獨立的原創異世界 2D 第一人稱冒險遊戲，不是《鱗片與種子：地下生態物語》。目前均為可修改的原型內容。


## V0.2.7｜精簡旅途紀錄顯示最新三則

- 依使用者最新決定，平常透明旅途紀錄顯示**三則完整事件單位**；每則客觀敘述和主角心聲各保留一行。過長文字在精簡模式以省略顯示，展開後保留完整內容。
- 新事件仍然接續在上一則下方並向上捲動；舊事件不刪除，完整紀錄透過日誌查看。手機橫式使用三列固定高度以降低遮擋。
- 本版已同步私人與公開原型，通過 JavaScript 語法與 CSS 目標檢查；iPhone Safari 真機畫面、實際文字截斷與滾動動畫仍待驗證。

## V0.2.6｜手機旅途紀錄滾動修復

- 修復歷史行動介面手機橫式 CSS 的 `nth-child` 規則，**不再隱藏第 3 則以後的紀錄**。
- 精簡 HUD 改用真正可捲動的容器，隱藏捲軸但不隱藏訊息；追加事件後等畫面完成排版再捲到最新紀錄。玩家仍可展開查看歷史。
- 再次到訪相同場景會寫「再次回到」與到訪次數，避免反覆顯示完全相同的移動文字；不改動原本事件、主線與存檔識別。
- 驗證：JavaScript 語法通過；獨立 CSS／滾動模擬在 Chromium 的 667×375、780×360、844×390、932×430 四種橫式尺寸可露出最新訊息，**不是整款遊戲的真實 Safari 測試**。iPhone 真機仍需確認。

## V0.2.5｜連續向上滾動的旅途紀錄

- 依使用者確認，旅途紀錄比照戰鬥訊息的**連續串流**：事件逐條追加在上一則之後，**不再每次清空／重畫整個列表**。
- 透明精簡 HUD 只露出末端的幾行文字；新的事件加入後，訊息**平滑向上捲動**，使用者仍看得到先前訊息接續的過程。
- 展開後保留可上下捲動的歷史；玩家手動閱讀舊訊息時，新事件不強行拉回底部。減少動態效果設定的裝置不啟用平滑滾動。
- 舊本機存檔識別與混合模式保持不變；重新開始／匯入時會重新建立訊息畫面。已完成程式語法檢查，**真實 iPhone Safari 動畫、捲動和背景遮擋仍待測**。

## V0.2.4｜場景優先的輕薄透明 HUD

- 考量 2D 場景容易被大型訊息面板遮蔽，**預設改成小型精簡浮動紀錄**，只顯示最新 2 筆事件＋主角感受與 1 個可點擊的目前行動。
- 精簡模式取消厚重面板邊框與背景模糊，改為漸層淡透明底＋文字陰影；點「展開」才開啟完整可捲動紀錄及更多可點擊行動，按「縮小」恢復。
- 不更動原本主線、探索事件及原存檔鍵，舊存檔缺少新欄位時自動顯示精簡模式；模式偏好由本機儲存。仍需要 iPhone Safari 實機畫面及點擊驗證。

## V0.2.3｜戰鬥紀錄式旅途訊息

- 左側「旅途紀錄」調整為半透明深色、緊湊的**彩色訊息串流**：依事件發生順序由上往下堆疊，最新訊息位於底部，接近底部時自動跟隨更新；手動往上捲動時不強制拉回底部。
- 混合模式仍是**唯一顯示模式**：每件事件可包含客觀訊息與主角簡短的內心想法，不提供三模式切換。
- 顏色區分路線移動、探索發現、人物對話、戰鬥、生活休息；增加已開啟 NPC 對話的簡要紀錄。
- 可互動地點仍位於訊息串流下方，點擊即可走現有路線；左側視窗可收合，完整旅途紀錄仍在右上角日誌。
- 存檔鍵與主線、隊伍、探索、委託狀態維持不變。**本版完成原始碼／JS 語法與公開、私人版本同步核對，但仍待 iPhone Safari 真機畫面、捲動、觸控測試。**

## V0.2.2 生活紀錄與可點選引導

- 採用唯一的**混合式旅途紀錄**：客觀事件與主角心聲同時呈現，不提供模式切換。
- 場景左側的小型紀錄窗可收合；依當前位置顯示可直接點擊的道路或互動項目，不會解鎖尚未開放的區域。
- 移動、首次發現、休息及測試戰鬥的資訊會持續寫入本機存檔；右上角旅程日誌新增「旅途」分頁，可回看記錄。
- 仍保留 V0.2.1 的「一個主要行動＋查看周遭」設計，玩家不必調查完才能前進，也不強迫閱讀紀錄。
- 舊 V0.1／V0.2 本機存檔繼續使用原儲存鍵，缺少新紀錄欄位時自動補上空列表。
- **本次驗證**：已核對程式腳本語法與公開／私人原型檔案一致；V0.2.2 的真實 iPhone Safari 點擊、介面遮擋、匯入舊存檔仍待實機確認。以下既有 Chromium 測試紀錄屬 V0.2.1。

## V0.2.1 操作精簡

依試玩回饋調整：場景下方只顯示**一個主要前進行動**與**「查看周遭」**，其餘支線、返回路線、交談與調查按需開啟，不再同時排列大量按鈕。探索紀錄仍可透過畫面右上角日誌圖示開啟；互動提示也可自行切換。重要劇情對話的選項與自由探索路線未刪除。

## V0.2.1 已實作

- **第一章**：被毀馬車、森林探索、未知物件與生物可選遭遇、四人救援、城門、旅店及背部紋印伏筆。
- **第二章**：旅店清晨；新增旅店大廳、城鎮街道、公會、近郊路口四個可自由往返的地區。
- **六人小隊**：與原救援四人再次交談，拜訪公共起居室後認識當天留守的兩名隊員；主角不自動成為第七名隊員或住客。
- **公會小委託**：可選擇檢查近郊路標，然後回公會回報。不接委託也能自由探索。
- **舊存檔相容**：V0.1 本機存檔鍵值、六人名單及進度延續，新增第二章存檔狀態與委託紀錄。
- **暫時美術與戰鬥**：場景由程式在 Canvas 原創繪製；回合制戰鬥只是實驗，尚非正式決定。

## 測試與限制

已以 Chromium／Playwright 模擬 932×430、844×390 手機橫式完整流程，通過公會委託、六人小隊再會、讀檔及 V0.1 舊存檔相容測試。667×375、780×360 橫式、1024×768 桌面按鈕未超出畫面，390×844 直式提供轉向提示。

**未驗證**：真實 iPhone Safari、正式美術與音樂、完整無障礙測試、正式戰鬥／報酬系統、雲端存檔、後續地下城劇情。原型的世界設定、未知物件和 NPC 台詞仍可修改。
