# 殘車之後｜地下城冒險公開測試 V0.4.8

> 《殘車之後》是**測試暫名**。這是獨立的原創異世界 2D 第一人稱冒險遊戲，不是《鱗片與種子：地下生態物語》。目前均為可修改的原型內容。




## V0.4.8｜「查看周遭」併入右側「地點」卡欄

- **需求**：使用者希望下方的「查看周遭」整合進已有的右側「地點」欄，減少重複按鈕與額外彈窗。
- **已實作**：原本底部「查看周遭 · N」及其選項視窗已取消；右側地點欄的可捲動內容上方新增「附近可互動（N 項）」，呈現目前場景的非路線、非主要／快捷互動，例如查看倒塌貨箱、車輪痕跡、舊石碑、古老石門、NPC 交談、休息、普通觀察與稀有生物單獨調查。點擊項目直接呼叫原本的實際互動函式，先自動收起右欄，不再額外出現「看看周遭」中介選單；原互動自身需要的對話或調查面板仍正常顯示。
- **路線去重**：通往其他地點的路線按鈕不會在「附近可互動」重複出現，仍由永久地點卡的「前往」負責；第一章救援、步行時間、驛站馬車選擇以及住處邀請條件繼續使用原有的路線控制。
- **保留常用行動**：底部「探索周遭 · 10分鐘」常駐主要或快捷按鈕保留；已有主要劇情行動保留；新路線、稀有生物、可收取普通材料、存檔與右側卡欄的收合／滑動功能均維持。沒有新增儲存欄位或更改本機存檔鍵。
- **檢驗**：私人與公開遊戲主程式一致、JS 語法通過，模擬 11 個現有場景的可用互動均與右側顯示項目一致，檢查非路線動作不漏掉、路線不重複、點擊後先收起右欄、特殊怪物入口和旅店休息入口均可用。未進行真實 iPhone Safari 視覺與手勢實測。


## V0.4.7｜探索不再強制彈出結果面板

- **使用者回饋**：V0.4.6 每次按「探索周遭」都跳出「探索結果」視窗，遮住主畫面。新規則是：探索完成後**不彈出任何結果面板，也不自動展開右側卡欄**；只在畫面短暫顯示提示（如找到新路線、殘骸、材料、道路線索），其餘資訊留在旅途紀錄。
- **路線**：新路線持續永久加入原右側「地點」滑出欄，NEW 徽標即時更新。玩家想查看才手動展開右欄。地圖、相鄰移動／救援門檻不變。
- **普通材料**：探索找到的待收取材料不再需要彈出視窗；右側地點欄上方增加「本地待收取材料」及逐項「收取」按鈕，顯示今日收取剩餘額度。右緣標籤若沒有新地點，可顯示「材料 N」提醒。收取後立即從暫存清單移除、材料加入原來的回收與探索材料欄，不會重複取得或跳視窗；已存於舊存檔的 pending 卡仍可領取。
- **觀察**：右欄中展開目前所在地卡片，可查看最近一次探索的環境觀察，以及未完成的路口線索。旅途紀錄仍保留探索次數、時間和發現。
- **不變**：探索每次 10 遊戲分鐘、可永久重複，原先每日材料上限、特殊怪物機率、獨立一次性馬車搜刮、NPC／劇情、原存檔鍵均保留。
- **程式測試**：已驗證 JavaScript 語法；反覆探索不顯示結果視窗、右欄不自動打開、NEW 即時出現、已發現普通材料在右欄可領取／不重複、探索時間／旅途紀錄與舊存檔可用；私人／公開 GitHub 原型一致。真實 iPhone Safari 視覺仍待實機檢查。

## V0.4.6｜右側滑出式地點卡欄 V1

- **使用者需求**：「新地點做成卡牌放在右邊滑動，有收放功能」；採取保留第一人稱風景、右側可滑出／收回的垂直地點卡欄，不把遊戲整體改為卡牌模式。
- **手機橫式與觸控**：畫面右側常駐窄型「◇ 地點」標籤，點擊可展開／收合；支援從右側標籤向左滑開、面板內向右滑回；面板內卡片上下自然捲動，不攔截場景其他觸控。抽屜以 transform 滑動、針對小螢幕收窄並保留原場景中央可見；減少動畫偏好時關閉過場。
- **地點卡內容**：從既有 routeDiscovery 的已知道路及 visits 的已到訪地點生成卡片。每張卡可單獨點開／收合；顯示地點名稱、目前／相鄰／已發現／已到訪狀態、可直接前往時的步行約略分鐘數、地點簡介或調查線索。沒去過的新地點有 NEW，抽屜標籤顯示 NEW 數量；點開卡片後記為已查看，不因只打開整欄而全部消除。
- **馬車殘骸探索點**：在玩家確實找到另一處林邊舊馬車殘骸後，另外加入卡片；僅在玩家站在林間小徑時可直接「調查殘骸」，不提供跨地圖傳送；原殘骸一次性搜集旗標仍維持。
- **行動安全**：只有**已解鎖且與目前所在地直接相鄰**的目的地卡有「前往」按鈕；遠方地點僅供查看。從林道前往救援前的主路仍先觸發四名冒險者的劇情，不能跳過救援；街道↔近郊仍以原本步行／驛站馬車選擇處理，受邀住處仍需 houseInvite。抽屜可與既有探索結果／對話／地圖面板共存，不會永久蓋住原場景；打開其他面板或移動時自動收起抽屜。
- **探索連動**：從常駐探索得到新路線後，抽屜的 NEW 徽標立即更新；探索結果的「永久路線卡」可直接點選「查看右側地點卡」，展開對應卡片，而不是直接瞬間傳送。
- **存檔相容**：在現有本機存檔鍵 dungeon_adventure_ch1_v01 下新增 placeCardsViewed 陣列記錄卡片查看狀態；舊存檔及匯入存檔自動補齊，不更動現有探索、材料收集、稀有生物、移動時間及劇情。
- **檢查結果**：私人／公開源碼一致；JavaScript 語法通過；抽屜收合、NEW 數量、單張展開、已讀記錄、相鄰道路可走但不可遠距傳送、第一章救援、近郊驛站馬車、受邀住處、舊存檔相容及左右觸控滑動等獨立邏輯測試通過。**真實 iPhone Safari 的實際視覺與手勢手感尚未實機驗證**。

## V0.4.5｜真正的常駐探索循環（參考《卡牌生存：熱帶島嶼》）

- **核心更正**：使用者要求「探索」能像《Card Survival: Tropical Island》一樣**持續出現**，不是 V0.4.4「新道路找完就消失」。本版讓所有現有場景都有常駐「探索周遭 · 10分鐘」；即使全部道路解鎖仍可反覆執行，每次直接推進 10 遊戲分鐘，不需現實等待。這是本作原創的固定場景、文字事件和輕量資源模式，並非照搬卡牌素材或演出。
- **探索產出**：每次探索形成「本次發現卡片」面板：可能找到永久新路線（地點卡）、未確認路口線索、普通環境觀察文字、普通材料，或在林道發現另一處舊馬車殘骸。探索事件按各地點的文字池輪替；城鎮／室內也有可反覆閱讀的生活觀察，但不會允許隨意撿走 NPC 物品。
- **道路漸進解鎖**：起點事故現場首次「探索周遭」10 分鐘保證發現林間小徑；其餘未發現的相連道路可在當前地點探索時以 30% 機率提早發現，若沒出現，**最多兩次探索**會保證解鎖該條相連道路。道路固定、發現後雙向永久保存，不重新抽取。林道往城鎮的主路在救援前仍只寫「前方主路（終點未明）」，不跳過救援；既有場景熱點與故事門檻照舊。
- **可取得的普通材料**：森林／殘骸／遺跡／近郊有地點專屬小材料池（碎木片、舊繩纖維、林木枝條、落葉纖維、石屑、苔石碎片、小石片、枯草纖維），每次有 70% 機率發現 1 張未收取材料卡，未收取卡會持續保存在新 s.exploration.pending。**每個地點每天最多收取 2 份普通材料**，最多暫存 3 張未收取卡；隔日可再次搜尋材料。收取後卡片會移除、相同 ID 不得重複領取；材料儲存到原有 s.recovery.parts，日誌的材料欄更新為「回收與探索材料」。
- **分開維持一次性與稀有事件**：原本第二輛舊馬車的可搜刮物品仍僅一次；現可從林道常駐探索發現舊殘骸（林道探索至多第 2 次必定遇到，**發現舊車不等於直接取得其掉落物**，需另去檢查）。普通材料是重複資源，不會重置任何劇情、鑑定、分解、月紋兔、拾鐵小妖、月露嫩芽、潮蔭嫩葉的一次性旗標。原極稀有遭遇 1.5%／2% 的每日判定入口與機率不變，**目前尚未自動整合進常駐探索按鈕**。
- **紀錄與存檔**：常駐探索的每次動作均有獨立次數、時鐘和旅途紀錄；新增 s.exploration（counts、routeProgress、pending、daily、last），可相容舊存檔與匯入存檔，原本 dungeon_adventure_ch1_v01 存檔鍵不變。原始 V0.4.4 的「探索附近道路 · 4分鐘」主動按鈕已整合成單一常駐探索入口；森林起點／林道的場景點擊探索熱點也不會再因為地圖全開而消失。
- **測試**：已核對私人／公開版 JavaScript 語法與資料一致；模擬測試證明起點首次探索解鎖小徑、同一地點可重複探索、探索後路線能永久保留、未完成路線在至多兩次探索內解鎖、普通材料每地每日上限 2、隔日再次產出、相同收取卡不能重複領取、路線未明時不提前洩漏城鎮、舊馬車殘骸獨立保存以及舊存檔可向後相容。**尚未在真實 iPhone Safari 確認探索卡片面板的排版與全部觸控流程**。

參考資料：社群整理的 Card Survival 探索機制說明 https://cardsurvival.fandom.com/wiki/Exploration ；遊戲實作與素材仍採原創。

## V0.4.4｜從起點逐步探索道路、永久路線卡

- **核心決策**：玩家希望從第一章破損馬車起點開始，之後的道路與可前往地點都透過探索或取得故事線索逐步發現。採**探索解鎖路線 → 永久卡片記錄 → 固定第一人稱場景通行**，而非全面轉成卡牌介面。地圖未知路線不提前洩漏名稱，可重訪已解鎖道路，不重新抽圖。
- **新遊戲**：初始 routeDiscovery 的 known 清單為空，事故現場第一次探索附近道路花 4 遊戲分鐘，解鎖與林間小徑相連的雙向路線。林道依序可搜尋「前方主路（終點未明）」、林間空地、苔生石門，每條第一次辨認各花 4 分鐘。前方主路第一次前進仍觸發原有四人救援，不會把城鎮位置預告給尚未遇到冒險者的玩家。
- **全區域架構**：原有 12 組雙向道路仍在 ROUTE_TIMES，新增 ROUTE_SEARCH_ORDER 分場景探索次序。城門、旅店、旅店大廳、街道和公會等以相同邏輯逐步發現；沒找到的路線不會出現在一般移動選項或畫面移動熱點內，地圖也只展示已發現地點卡。邀請進入冒險小隊住處依舊需 houseInvite。第二章旅店早晨劇情會依店員告知的方向，自動解鎖旅店大廳與街道的聯繫，屬於合理的「取得路線情報」例外。
- **UI**：新增帶金色邊框的「新路線卡」現場發現面板（名稱、線索、步行時間、前往或稍後）及地圖中的永久卡片；若尚有未知道路，地圖只提供「附近有未確認道路」文字提示，不暴露目的地。
- **舊存檔保護**：沿用 dungeon_adventure_ch1_v01 存檔鍵；已在 V0.4.3 或更早版本遊玩的舊存檔缺少 routeDiscovery 時，會自動保留過去版本已有的全部 12 條可通行路線，避免中途被鎖在地點。**要體驗從零開始逐條發現，請在設定中重新開始新旅程（會覆寫既有本機存檔，建議先匯出備份）**。
- **既有系統不變**：馬車事故故事、救援三種選擇、固定森林、舊車殘骸搜集、鑑定分解、極低機率月紋兔與拾鐵小妖、採集植物、日夜和步行／驛站馬車時間均保留。
- **驗證**：私人／公開源碼已同步，JavaScript 語法通過。獨立路線測試通過：初始無路、首次探索4分鐘、雙向永久解鎖、重複不扣時、林道主路不提前揭示城鎮、主要劇情仍觸發救援、兩條森林支路依序發現、從街道能找到回城門的路、小隊住處需要邀請、舊存檔12條道路皆保留。真實 iPhone Safari 全流程視覺與觸控仍待驗證。

## V0.4.2｜固定森林的稀有生物與特殊食材前導

- 使用者確定將原提案「裂光石門蟲」**替換為兔形稀有生物「月紋兔」**；不再使用原蟲類設計。另一種備選森林生物「霧枝行獸」可留作更晚的規劃，非本版實作。
- 現階段完成兩種文字型**極低機率遭遇**：**拾鐵小妖**（林邊舊馬車殘骸已發現、黃昏或夜間、2%）與**月紋兔**（舊石門、清晨或黃昏、1.5%）。玩家透過場景原有「查看周遭」動作尋找，**每個地點每個遊戲日最多搜尋 1 次，每次 8 分鐘**；無須現實等待。未出現時可能只留下痕跡與記錄，不強制戰鬥，也不保證短期內刷到。尚未有動物／小妖正式立繪、戰鬥敵人、動態生成地圖。
